# Camper Route Planner branding

The current artwork is a project-specific logo for **Camper Route Planner**.
It follows the approved SmartCamper Suite design language (deep navy, cyan,
blue and warm orange) without reusing the Suite wordmark.

The source artwork is retained as `camper-route-planner-source.png`. The HA
integration variants are deterministic resized/cropped derivatives:

- `custom_components/camper_route_planner/brand/icon.png` — 256×256
- `custom_components/camper_route_planner/brand/icon@2x.png` — 512×512
- `custom_components/camper_route_planner/brand/logo.png` — 1024×256
- `custom_components/camper_route_planner/brand/logo@2x.png` — 2048×512

The old `HOME ASSISTANT · OFFLINE / MOCK ROUTING` artwork is no longer used by
the README or the integration branding paths.
