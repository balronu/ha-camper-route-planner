# Camper Route Planner v0.1.6-beta.7

## Deutsch

### Routenzustand und Dashboard-Karte

- Veraltete Routengeometrie wird nach Stationsänderungen oder fehlgeschlagener
  Neuberechnung nicht mehr als aktuelle Route in der normalen Dashboard-Karte
  dargestellt. Stattdessen bleiben nur die aktuellen Stationspunkte bzw. eine
  Vorschau sichtbar; die vorhandene Berechnung wird weiterhin ausdrücklich als
  veraltet angezeigt.
- Beim Laden einer gespeicherten Route werden Stationsliste, Koordinaten und
  Routenergebnis gemeinsam aus demselben Datensatz wiederhergestellt.
- Eine verspätete Tracker-Antwort kann den Startpunkt einer inzwischen geladenen
  gespeicherten Route nicht mehr überschreiben.
- Beim Wechsel auf einen neuen Konfigurations-Entry wird der bisherige
  Routenzustand vollständig zurückgesetzt. Es erfolgt keine automatische
  Neuberechnung.

### Kompatibilität und Hinweise

- Die Popup-Karte behält ihre bestehende Bedienung, Fokusführung und
  Scroll-Sperre. Sie verwendet weiterhin die vorhandenen Routendaten und stellt
  keine zusätzliche Provider-Anfrage.
- Gespeicherte Routen, Fahrzeugprofile, Zoe, VM 104 und produktive
  NaKordoni-Anfragen wurden nicht verändert bzw. verwendet.
- v0.1.5 bleibt Stable. Beta 7 ist eine freiwillige Vorabversion für Tests;
  nach dem Update ist kein manueller Migrationsschritt erforderlich.
- Der automatische Kartenzoom beim Laden gespeicherter Routen wurde in dieser
  Beta nicht als vollständig behoben bestätigt und bleibt ein offener Punkt.

## English

### Route state and dashboard map

- After station changes or a failed recalculation, stale route geometry is no
  longer shown as the current route in the normal dashboard map. Current
  station points or a preview remain visible, while the existing calculation is
  explicitly marked as outdated.
- Loading a saved route restores the station list, coordinates, and route result
  together from the same record.
- A late tracker response can no longer overwrite the origin of a saved route
  that has already been loaded.
- Switching to a new configuration entry fully resets the previous route state.
  No automatic recalculation is performed.

### Compatibility and notes

- The existing popup map interaction, focus handling, and background scroll lock
  are preserved. It continues to use the existing route data and makes no
  additional provider request.
- Saved routes, vehicle profiles, Zoe, VM 104, and productive NaKordoni
  requests were not changed or used.
- v0.1.5 remains Stable. Beta 7 is an optional preview release for testing;
  no manual migration step is required after updating.
- Automatic map zoom when loading saved routes was not confirmed fully fixed in
  this beta and remains open.
