# Camper Route Planner v0.1.0-beta.6

## Deutsch

### Fehlerbehebung

- Die Leaflet-Karte kapselt ihren Karten-Handle jetzt intern über ein
  `Symbol`.
- Die Karte verwendet die namespaced CSS-Klasse `crp-leaflet-map` und
  veröffentlicht weder `_leafletMap` noch `leaflet-map`.
- Dadurch können andere Custom Cards, insbesondere Flightradar24, beim
  Resize nicht mehr versehentlich die CRP-Karte invalidieren. Der zuvor
  nach Karten-Neuaufbau beobachtete `_leaflet_pos`-Fehler ist reproduzierbar
  abgedeckt.
- Der Regressionstest prüft die Interoperabilität im Chromium-Desktop- und
  Mobile-Lauf einschließlich erfolgreicher Leaflet-Karte und Fallbackpfaden.

### Installation und Migration

In HACS als **Custom repository** die Pre-release-Version `v0.1.0-beta.6`
auswählen. Alternativ kann der Ordner
`custom_components/camper_route_planner/` kopiert und Home Assistant danach
neu gestartet werden. Bestehende YAML-Konfigurationen und Config Entries
bleiben unverändert; eine manuelle Lovelace-Ressource ist weiterhin nicht
erforderlich. Nach dem Update muss ein bereits geöffneter Browser die neue
versionierte Resource laden, gegebenenfalls durch einen normalen Reload.

### Einschränkungen

- Dies ist eine Beta mit deterministischem Mock-Routing und keine geprüfte
  Wohnmobilnavigation.
- Ein echter HACS-UI-Installationslauf, produktiver HA-Browserlauf und iOS
  Safari/WebKit wurden nicht ausgeführt.
- VM 104, Dashboards, Camper Travel Journal, Flightradar24 und andere
  Repositories wurden nicht verändert; es wurden keine Nakordoni-Live-Aufrufe
  ausgeführt.

## English

### Fix

- The Leaflet map now keeps its map handle private through a `Symbol`.
- The card uses the namespaced `crp-leaflet-map` CSS class and no longer
  exposes `_leafletMap` or `leaflet-map`.
- Other custom cards, especially Flightradar24, can therefore not invalidate
  the CRP map during resize. The previously observed `_leaflet_pos` error after
  map rebuild is covered by a reproducible regression test.
- Chromium desktop and mobile tests cover the interoperability assertion,
  successful Leaflet rendering, and all existing fallback paths.

### Installation and migration

In HACS, add the repository as a **Custom repository** and select the
`v0.1.0-beta.6` pre-release. Alternatively copy
`custom_components/camper_route_planner/` and restart Home Assistant. Existing
YAML configuration and Config Entries remain unchanged; no manual Lovelace
resource is required. An already open browser may need a normal reload to
load the new versioned resource.

### Limitations

- This is a beta using deterministic mock routing, not verified motorhome
  navigation.
- A real HACS UI installation, productive HA browser run, and iOS Safari/WebKit
  were not executed.
- VM 104, dashboards, Camper Travel Journal, Flightradar24, and other
  repositories were not changed; no live Nakordoni calls were made.
