# Camper Route Planner v0.1.0-beta.19

## Deutsch

Beta.19 konsolidiert die Provider-Laufzeitbindung und bereitet den
Nakordoni-Transport offline vor.

### Änderungen und Fehlerbehebungen

- Der ausgewählte Provider wird aus den aktuellen Config-Entry-Optionen
  aufgebaut und nach Optionsänderungen neu geladen.
- Mock, Nakordoni und Nakordoni Motorhome bleiben getrennte Backend-Pfade;
  es gibt keinen stillen Mock-Fallback.
- Der asynchrone Home-Assistant-HTTP-Transport unterstützt Bearer-Key,
  Timeout, begrenzte Quota-Header und das dokumentierte `via`-Format.
- GeoJSON-Routengeometrie wird korrekt von `lon,lat` nach `lat,lon`
  normalisiert.
- Motorhome-Fahrzeugwerte stammen weiterhin aus dem ausgewählten Profil.

### Installation und Einschränkungen

Beta.19 ist zum Zeitpunkt dieses Dokuments noch nicht veröffentlicht. Es
wurden keine echten Nakordoni-, Geoapify- oder CARTO-Aufrufe durchgeführt.
Der Motorhome-Livepfad bleibt bis zur bestätigten Motorhome-API-Freigabe und
einem separat autorisierten Probeaufruf deaktiviert. Truck-Routing darf nicht
als geprüfte Wohnmobilnavigation dargestellt werden.

Validiert wurden isolierte Home-Assistant-Fixtures, Python, Frontend,
Chromium, Hassfest, Quality/Secret-Scan und der Frontend-Build.

## English

Beta.19 consolidates provider runtime binding and prepares the Nakordoni
transport offline.

### Changes and fixes

- The selected provider is built from the current Config Entry options and is
  reloaded after options changes.
- Mock, Nakordoni, and Nakordoni Motorhome remain separate backend paths; no
  silent Mock fallback is used.
- The asynchronous Home Assistant HTTP transport supports Bearer keys,
  bounded timeouts, safe quota headers, and the documented `via` format.
- GeoJSON route geometry is normalized correctly from `lon,lat` to `lat,lon`.
- Motorhome dimensions and weight continue to come from the selected vehicle
  profile.

### Installation and limitations

Beta.19 has not been published at the time of this document. No real
Nakordoni, Geoapify, or CARTO requests were made. The Motorhome live path
remains disabled until the Motorhome API contract and account permission are
confirmed and a separately authorized probe is approved. Truck routing must
not be presented as verified motorhome navigation.

Validation covers isolated Home Assistant fixtures, Python, frontend,
Chromium, Hassfest, quality/secret scanning, and the frontend build.
