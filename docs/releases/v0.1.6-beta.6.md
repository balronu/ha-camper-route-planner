# Camper Route Planner v0.1.6-beta.6

## Deutsch

### NaKordoni-Fehlerbehandlung

- HTTP 400 mit `error.reason=point_not_routable` wird als eigener Fehler mit
  verständlichem Hinweis auf den betroffenen Wegpunkt behandelt.
- HTTP 504 mit `route_timeout` wird als Zeitüberschreitung ausgewiesen. Der
  Transport wiederholt 504 nicht automatisch; ein erneuter Versuch bleibt eine
  bewusste Benutzeraktion.
- `X-Request-Id` beziehungsweise JSON-`request_id` wird nur in einem begrenzten
  Format übernommen und ausschließlich in der temporären Admin-Diagnose
  angezeigt. Zugangsdaten, rohe Header und Antworttexte bleiben ausgeschlossen.

### Read-only-Prüfung des ungewöhnlichen Startpunkts

Die Koordinate `43.1172, -9.8083` wurde in Quelltext, Tests und Git-Historie
nicht gefunden. Der Repository-Code kann den Ursprung daher nicht belegen.
Mögliche externe Quellen wie ein Home-Assistant-Tracker, manuelle Eingabe,
Geocoding oder eine gespeicherte Route wurden nicht produktiv ausgelesen;
keine Ursache wird behauptet.

### POI-Konzept, noch keine Implementierung

Die optionale NaKordoni-Funktion `include=parking,fuel` mit `fuel=diesel` ist
in [NAKORDONI-POI-CONCEPT.md](../NAKORDONI-POI-CONCEPT.md) beschrieben.
Beta 6 führt keine POI-Anfragen aus. Antwortstruktur, Dieselpreise,
Fahrzeugtauglichkeit, Laufzeit und Kontingentwirkung bleiben vor einer
separaten Freigabe offen.

### Kompatibilität und Grenzen

Bestehende gespeicherte Routen, Fahrzeugprofile, GPX-/PDF-Export und die
Routingparameter bleiben unverändert. v0.1.5 bleibt Stable; diese Version ist
eine Beta. VM 104, Zoe, gespeicherte Routen, Zugangsdaten und produktive
NaKordoni-Anfragen wurden nicht verändert bzw. ausgeführt.

## English

### NaKordoni error handling

- HTTP 400 with `error.reason=point_not_routable` is exposed as a dedicated
  error that identifies the affected waypoint safely.
- HTTP 504 with `route_timeout` is reported as a timeout. The transport does
  not retry 504 automatically; retrying remains an explicit user action.
- `X-Request-Id` or JSON `request_id` is accepted only in a bounded format and
  shown only in the temporary administrator diagnostic. Credentials, raw
  headers, and response bodies remain excluded.

### Read-only investigation of the unusual origin

The coordinate `43.1172, -9.8083` was not found in source, tests, or Git
history. The repository therefore cannot establish its origin. Possible
external sources such as a Home Assistant tracker, manual input, geocoding, or
a saved route were not read from production; no cause is claimed.

### POI concept, no implementation yet

The optional `include=parking,fuel` and `fuel=diesel` design is documented in
[NAKORDONI-POI-CONCEPT.md](../NAKORDONI-POI-CONCEPT.md). Beta 6 makes no POI
requests. Response shape, diesel prices, vehicle suitability, latency, and
quota impact remain open pending separate approval.

### Compatibility and limits

Existing saved routes, vehicle profiles, GPX/PDF export, and routing parameters
remain unchanged. v0.1.5 remains Stable; this is a beta release. VM 104, Zoe,
saved routes, credentials, and productive NaKordoni requests were not changed
or executed.
