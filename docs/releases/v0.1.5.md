# Camper Route Planner v0.1.5 Stable

## Deutsch

### Änderungen

- Gespeicherte Routen übernehmen Start, Ziel und Zwischenziele mit den
  vorhandenen Koordinaten; alte Formularentwürfe überschreiben geladene Werte
  nicht.
- Optionale `depart_at`- und `arrive_at`-Werte werden ohne gesetzte Zeit nicht
  als `None` übertragen. Vorhandene gültige Zeiten bleiben erhalten.
- Nach einer fehlgeschlagenen Neuberechnung werden alte Routenergebnisse als
  veraltet gekennzeichnet.
- Die administrative Request-Diagnose ist standardmäßig deaktiviert, nur für
  Administratoren verfügbar und gilt genau für einen Backend-Versuch.
- Native Home-Assistant-Diagnostics enthalten keine Request-Koordinaten,
  Waypoints, sensiblen Requestdaten, Zugangsdaten oder Authentifizierungsdaten.
  Diagnoseinformationen werden nach dem einmaligen Abruf verworfen.
- „Diagnose kopieren“ kopiert den bereinigten JSON-Bericht; bei nicht verfügbarer
  Zwischenablage steht ein manuell markierbarer Fallback bereit.
- Die Entwicklerdiagnose ist standardmäßig ausgeblendet und kann pro Karte
  ausschließlich von Administratoren aktiviert werden.

### Kompatibilität und Rollback

- Bestehende gespeicherte Routen und Fahrzeugprofile werden ohne Migration
  weiterverwendet.
- Bestehende Dashboards werden nicht automatisch verändert.
- Vor dem Wechsel sollte ein Home-Assistant-Backup erstellt werden.
- Rollback: in HACS ausdrücklich Stable `v0.1.3` auswählen oder das unveränderte
  Release-Asset von `v0.1.3` installieren. Den historischen Tag `v0.1.4` nicht
  als Stable-Ziel verwenden.

## English

### Changes

- Saved routes preserve existing origin, destination, and waypoint coordinates;
  old form drafts no longer overwrite loaded values.
- Optional `depart_at` and `arrive_at` values are omitted when unset instead
  of being sent as `None`. Valid existing times remain intact.
- Failed recalculations mark previous route results as stale.
- Administrative request diagnostics are disabled by default, restricted to
  administrators, and apply to exactly one backend attempt.
- Native Home Assistant diagnostics contain no request coordinates, waypoints,
  sensitive request data, credentials, or authentication data. Diagnostic data
  is discarded after the one-time retrieval.
- “Copy diagnostics” copies the sanitized JSON report and provides a manually
  selectable fallback when the clipboard is unavailable.
- Developer diagnostics are hidden by default and can only be enabled per card
  by administrators.

### Compatibility and rollback

- Existing saved routes and vehicle profiles continue without migration.
- Existing dashboards are not changed automatically.
- Create a Home Assistant backup before changing versions.
- Rollback: explicitly select Stable `v0.1.3` in HACS or install its unchanged
  release asset. Do not use the historical `v0.1.4` tag as the Stable target.
