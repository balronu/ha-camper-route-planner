# Camper Route Planner v0.1.4-beta.1

## Deutsch

### Inhalt

- Eine ausdrücklich aktivierbare Diagnoseansicht für genau die nächste manuelle Routenberechnung.
- Anzeige der tatsächlich providergebundenen v3-Parameter ohne API-Schlüssel, Token oder Authentifizierungsheader.
- Erfasst werden API-Version und Endpunkt, Start/Ziel, Waypoints in Reihenfolge, Fahrzeugwerte, Routingoptionen, HTTP-/Quellen-/Cache-/Retry-Status sowie die übernommenen `distance_m`- und `duration_s`-Werte.
- Die Diagnose ist flüchtig, wird nach dem nächsten Berechnungsversuch zurückgesetzt und wird nicht in der normalen Home-Assistant-Diagnostik oder in gespeicherten Routen abgelegt.
- `(0,0)` wird als ungültige vollständige Koordinate abgewiesen. Koordinaten auf dem Äquator oder Nullmeridian bleiben zulässig, solange nicht beide Werte null sind.

### Einschränkungen

- Die Diagnosefunktion ist standardmäßig deaktiviert und erfordert eine bewusste Administratoraktion.
- Die Beta wurde nicht auf Home Assistant VM 104 installiert und führt keine produktiven Routinganfragen aus.

## English

### Contents

- An explicitly activated, one-shot diagnostics view for the next manual route calculation.
- The actual provider-bound v3 parameters are shown without API keys, tokens, or authentication headers.
- The view captures API version and endpoint, origin/destination, ordered waypoints, vehicle values, routing options, HTTP/source/cache/retry status, and the returned `distance_m` and `duration_s` fields.
- Diagnostics are volatile, reset after the next calculation attempt, and are excluded from native Home Assistant diagnostics and saved routes.
- `(0,0)` is rejected as an invalid complete coordinate. Equator and null-meridian coordinates remain valid when only one component is zero.

### Limitations

- Diagnostics are disabled by default and require a deliberate administrator action.
- This beta was not installed on Home Assistant VM 104 and performs no productive routing requests.
