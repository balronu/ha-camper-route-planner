# Camper Route Planner v0.1.0-beta.20

## Deutsch

Beta.20 ist eine GitHub-Pre-release-Testversion vor Stable `v0.1.0`.

### Änderungen

- PR #34 wurde gemergt; die Navigationsübergabe nutzt auf iOS `maps://`, auf
  Android `geo:` und auf Desktop OpenStreetMap als Fallback.
- Der Options Flow zeigt nur `Nakordoni` und `Mock (offline)`. `Nakordoni`
  verwendet intern weiterhin `nakordoni_motorhome`; der alte gespeicherte Wert
  `nakordoni` wird nicht stillschweigend migriert.
- Fahrzeugänderungen sind standardmäßig auf **Keine Änderungen an Fahrzeugen**
  gesetzt. Provider-, Karten- und Key-Änderungen überspringen die Profilseite
  und erhalten Profile, IDs, Tracker und Routenreferenzen.
- Die versionierte Lovelace-Ressource, Manifest, Bundle und HACS-Paketdaten
  sind auf `0.1.0-beta.20` synchronisiert.

### Installation und Praxistest

Beta.20 ist ausdrücklich ein GitHub-Pre-release. In HACS muss die Beta-/Pre-
release-Auswahl aktiviert und `v0.1.0-beta.20` ausgewählt werden; ein Git-Tag
allein installiert nichts. Nach dem Update die Lovelace-Ressource neu laden,
falls ein alter Browser-Cache sichtbar bleibt.

Für den manuellen Test in einer Testinstallation: vorhandenes Fahrzeugprofil
und Tracker prüfen, zunächst nur den Provider oder Key ändern und kontrollieren,
dass das Profil unverändert bleibt. Danach eine Navigation auf iOS/Android und
Desktop prüfen. Die externe App kann Zwischenziele oder Fahrzeugbeschränkungen
anders behandeln; GPX bleibt der verlässliche Exportpfad.

### Einschränkungen

- Es wurden keine echten Nakordoni-, Geoapify- oder HACS-Installationsaufrufe
  durch OpenClaw ausgeführt.
- `maps://` und `geo:` garantieren nicht die Öffnung einer frei gewählten
  Standard-Navigations-App auf jedem Gerät.
- Externe Apps können die Route neu berechnen und Zwischenziele oder
  Wohnmobilparameter unvollständig übernehmen.
- Stable `v0.1.0` wird nicht veröffentlicht.

## English

Beta.20 is a GitHub pre-release test version before Stable `v0.1.0`.

### Changes

- PR #34 was merged; navigation handoff uses `maps://` on iOS, `geo:` on
  Android, and OpenStreetMap directions as the desktop fallback.
- The Options Flow exposes only `Nakordoni` and `Mock (offline)`. `Nakordoni`
  continues to use the internal `nakordoni_motorhome` provider; the old stored
  `nakordoni` value is not silently migrated.
- Vehicle management defaults to **No vehicle changes**. Provider, map, and key
  changes skip the profile page and preserve profiles, IDs, trackers, and route
  references.
- The versioned Lovelace resource, manifest, bundle, and HACS package metadata
  are synchronized to `0.1.0-beta.20`.

### Installation and field test

Beta.20 is explicitly a GitHub pre-release. Enable/select pre-releases in HACS
and choose `v0.1.0-beta.20`; a Git tag alone does not install anything. Reload
the Lovelace resource after updating if an old browser cache remains visible.

In a test installation, verify the existing vehicle profile and tracker, first
change only the provider or key, and confirm that the profile is unchanged.
Then test navigation handoff on iOS/Android and desktop. External apps may
handle waypoints or vehicle restrictions differently; GPX remains the reliable
export path.

### Limitations

- OpenClaw made no real Nakordoni, Geoapify, or HACS installation requests.
- `maps://` and `geo:` do not guarantee opening a user-selected default
  navigation app on every device.
- External apps may recalculate the route and incompletely carry over waypoints
  or motorhome parameters.
- Stable `v0.1.0` is not being published.
