# Camper Route Planner v0.1.0-beta.21

## Deutsch

Beta.21 ist der letzte geplante Test-Beta-Kandidat vor Stable `v0.1.0`.

- Die Navigationsübergabe folgt jetzt dem bewährten direkten HTTPS-Anchor-Muster
  aus Mobile Fuel Stations.
- iOS verwendet Apple Maps Directions, Android Google Maps Directions; Desktop
  behält den OpenStreetMap-Directions-Fallback.
- Die aktuell berechneten Zielkoordinaten werden URL-kodiert übergeben. Ohne
  gültiges Ziel bleibt die Navigation deaktiviert. Zwischenziele werden in den
  mobilen Links bewusst nicht behauptet; GPX bleibt für komplexe Routen.
- Die erste Options-Flow-Seite zeigt die Fahrzeugverwaltung auf Deutsch und
  Englisch statt der technischen Werte `vehicle_action`, `none`, `edit` und
  `add`. Die gespeicherten internen Werte bleiben unverändert.
- GPX-Route, GPX-Track und kombinierter GPX-Export bleiben erhalten.
- Der Sicherheitshinweis bleibt bestehen: Externe Navigations-Apps können die
  Strecke neu berechnen und Fahrzeugparameter wie Länge, Breite, Höhe, Gewicht
  oder Achszahl ignorieren.

Diese Beta ändert keine produktiven Home-Assistant-Daten, Fahrzeugprofile,
Tracker, API-Keys oder die Referenzintegration Mobile Fuel Stations. Es wurden
keine echten Nakordoni-Anfragen ausgeführt. Stable `v0.1.0` wird nicht mit
dieser Veröffentlichung freigegeben.

## English

Beta.21 is the final planned test-beta candidate before Stable `v0.1.0`.

- Navigation now uses the proven direct HTTPS-anchor pattern from Mobile Fuel
  Stations.
- iOS uses Apple Maps Directions, Android uses Google Maps Directions, and the
  desktop OpenStreetMap Directions fallback remains available.
- The current calculated destination coordinates are URL-encoded. Navigation
  stays disabled without a valid destination. Mobile links deliberately omit
  waypoints; GPX remains the path for complex routes.
- The first Options Flow step now shows user-facing vehicle-management labels
  in German and English instead of the technical values `vehicle_action`,
  `none`, `edit`, and `add`. Stored internal values remain unchanged.
- GPX route, GPX track, and combined GPX export remain available.
- The safety notice remains: external navigation apps may recalculate the route
  and ignore vehicle parameters such as length, width, height, weight, or axle
  count.

This beta changes no productive Home Assistant data, vehicle profiles, trackers,
API keys, or the Mobile Fuel Stations reference integration. No real Nakordoni
requests were executed. Stable `v0.1.0` is not released by this publication.
