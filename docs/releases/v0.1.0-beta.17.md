# Camper Route Planner v0.1.0-beta.17

## Deutsch

Beta.17 veröffentlicht die Phase-3T-Korrekturen für den Lebenszyklus der
Leaflet-Karte und die Zwischenzielbearbeitung.

### Änderungen und Fehlerbehebungen

- Die bestehende Leaflet-Instanz und der CARTO-Tile-Layer bleiben beim
  Hinzufügen, Ändern, Entfernen und Umordnen von Zwischenzielen erhalten.
- Marker-Icons sind vollständig im Bundle enthalten: Start grün,
  Zwischenziel orange und Ziel rot; externe Bilddateien sind nicht nötig.
- `fitBounds()` berücksichtigt Start, Ziel und alle Zwischenziele mit
  Randabstand.
- Vor dem echten Mock-Routing zeigt eine Luftlinie die aktuelle Punktfolge;
  sie wird nicht als Straßenroute ausgegeben.
- Source-, Dist- und installierbares HA-Frontend-Bundle sind synchron.

### Installation und Einschränkungen

Beta.17 ist ein GitHub-Pre-release für HACS. Pre-releases müssen in HACS
ausdrücklich aktiviert bzw. ausgewählt werden. Die Prüfung umfasst isolierte
HA-2026.10.1-Fixtures, Mock-Daten, Chromium Desktop/Touch und alle sechs
GitHub-CI-Gates.

Echte CARTO-, Geoapify- und Nakordoni-Aufrufe sowie VM 104 wurden nicht
verwendet. Ein echter WebKit/iOS-Test bleibt offen; der manuelle iPhone-
Praxistest ist erforderlich. Die Integration bleibt deterministisches
Mock-Routing und ist keine geprüfte Wohnmobilnavigation.

## English

Beta.17 publishes the Phase 3T fixes for Leaflet map lifecycle and waypoint
editing.

### Changes and fixes

- The existing Leaflet instance and CARTO tile layer remain in place while
  waypoints are added, edited, removed, and reordered.
- Marker icons are fully bundled: green origin, orange waypoint, and red
  destination; no external image files are required.
- `fitBounds()` includes the origin, destination, and all waypoints with
  padding.
- Before real mock routing, a straight preview line shows the current point
  sequence; it is not presented as a road route.
- Source, distribution, and installable HA frontend bundles are synchronized.

### Installation and limitations

Beta.17 is a GitHub pre-release for HACS. Explicitly enable or select
pre-releases in HACS. Validation covers isolated HA 2026.10.1 fixtures,
mocked data, Chromium desktop/touch, and all six GitHub CI gates.

No productive CARTO, Geoapify, or Nakordoni requests were made, and VM 104 was
not changed. A real WebKit/iOS test remains open; the manual iPhone practical
test is required. The integration still uses deterministic mock routing and
is not verified motorhome navigation.
