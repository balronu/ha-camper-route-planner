# Camper Route Planner v0.1.2-beta.3

## Deutsch

Diese Beta korrigiert mehrere Datenketten- und Anzeigeprobleme aus dem
Praxisfeedback, ohne VM 104 oder gespeicherte Routen zu verändern.

- V3-Mautantworten mit `total_eur`/`by_country` werden in die stabile
  Anzeigeform normalisiert; unvollständige Preise bleiben ausdrücklich
  unvollständig.
- Konkrete Grenzübergänge, explizit inferierte Länderfolgen und unbekannte
  internationale Grenzdaten werden getrennt dargestellt.
- Strukturierte Verkehrsdaten werden nicht mehr als `[object Object]` gerendert.
- Ungültige gespeicherte `0/0`-Punkte werden nicht als Routing-Eingaben geladen.
- Profilwerte für Tank, Verbrauch und Dieselpreis bleiben aktiv, wenn lokale
  Eingabefelder leer sind; für das Referenzbeispiel ergibt sich ca. 561,26 €.
- Geänderte Routenparameter markieren ein vorhandenes Ergebnis als veraltet;
  es erfolgt keine automatische Neuberechnung.
- Der Kartenstatus zeigt den konfigurierten NaKordoni-v2/v3-Modus eindeutig.

Alle Änderungen wurden offline mit synthetischen Fixtures geprüft. Es wurden
keine echten NaKordoni-Routingaufrufe durchgeführt. Diese Beta ist keine
Bestätigung rechtlicher oder praktischer Befahrbarkeit. Stable `v0.1.1`,
VM 104, HACS, Zoe, gespeicherte Routen und API-Schlüssel bleiben unverändert.

## English

This beta fixes several data-chain and display issues from practical feedback
without changing VM 104 or saved routes.

- V3 toll responses using `total_eur`/`by_country` are normalized to the
  stable display shape; incomplete prices remain explicitly incomplete.
- Concrete crossings, explicitly inferred country transitions, and unknown
  international border data are displayed as separate states.
- Structured traffic data is no longer rendered as `[object Object]`.
- Invalid saved `0/0` points are not loaded as routing inputs.
- Profile tank, consumption, and diesel-price values remain effective when
  local editor fields are empty; the reference example is approximately
  €561.26.
- Changed route parameters mark an existing result stale; no automatic
  recalculation is triggered.
- The card status identifies the configured NaKordoni v2/v3 mode.

All changes were validated offline with synthetic fixtures. No real Nakordoni
routing calls were performed. This beta does not prove legal or practical
route passability. Stable `v0.1.1`, VM 104, HACS, Zoe, saved routes, and API
keys remain unchanged.
