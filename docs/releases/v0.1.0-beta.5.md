# Camper Route Planner v0.1.0-beta.5

## Deutsch

### Fehlerbehebung

- Die GitHub-Actions-Validierung reagiert jetzt auf Versionstags `v*` und kann
  kontrolliert per `workflow_dispatch` wiederholt werden.
- Das Beta.4-Tag bleibt unverändert erhalten; diese Beta.5 basiert auf dem
  korrigierten Main-Stand und besitzt eine eigene vollständige Tag-CI.
- Das Lovelace-Bundle, Manifest, Cache-Parameter und die Dokumentation sind
  auf `v0.1.0-beta.5` synchronisiert.

### Installation

In HACS als **Custom repository** hinzufügen und die Pre-release-Version
`v0.1.0-beta.5` auswählen. Alternativ den Ordner
`custom_components/camper_route_planner/` aus diesem Repository kopieren und
Home Assistant danach neu starten. Bestehende Dashboards werden nicht
geändert; eine manuelle Lovelace-Ressource ist nicht erforderlich.

### Einschränkungen

- Dies ist eine Beta mit deterministischem Mock-Routing; keine geprüfte
  Wohnmobilnavigation.
- Ein echter HACS-UI-Installationslauf und iOS-Safari konnten in der isolierten
  CI-Umgebung nicht ausgeführt werden.
- VM 104 wurde nicht geändert und es wurden keine Nakordoni-Live-Aufrufe
  ausgeführt.

## English

### Fixes

- GitHub Actions validation now runs for version tags `v*` and supports
  controlled reruns through `workflow_dispatch`.
- The Beta.4 tag remains unchanged; this Beta.5 is based on the corrected main
  branch and has its own complete tag-CI run.
- The Lovelace bundle, manifest, cache parameter, and documentation are
  synchronized to `v0.1.0-beta.5`.

### Installation

Add the repository to HACS as a **Custom repository** and select the
pre-release `v0.1.0-beta.5`. Alternatively copy
`custom_components/camper_route_planner/` from this repository and restart
Home Assistant. Existing dashboards are not changed and no manual Lovelace
resource is required.

### Limitations

- This is a beta using deterministic mock routing; it is not verified motorhome
  navigation.
- A real HACS UI installation and iOS Safari run were not available in the
  isolated CI environment.
- VM 104 was not changed and no live Nakordoni calls were made.
