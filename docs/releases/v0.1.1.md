# Camper Route Planner v0.1.1 Stable

## Deutsch

`v0.1.1` ist die Stable-Veröffentlichung auf Basis von Beta.16. Bestehende
Fahrzeugprofile, Config Entries, gespeicherte Routen und GPX-Daten bleiben
kompatibel; Stable `v0.1.0` bleibt als Rollback-Version erhalten.

### Änderungen und Fehlerbehebungen

- Erweiterte Wohnmobil-Routenplanung mit Verkehrs- und Routenoptionen,
  Vermeidungsoptionen, ECO-Routing und alternativen Routen.
- Abfahrts- und Ankunftszeiten sowie verbesserte Karten- und Mobile-Darstellung.
- Fahrzeugbezogene Kraftstoffplanung mit Tankfüllstand in Litern oder Prozent,
  Reichweitenberechnung und manueller Kraftstoffkostenschätzung.
- Ein neutraler Planungshinweis zeigt erforderliche Tankstopps bzw. zusätzlichen
  Kraftstoffbedarf, ohne automatische Tankstopps auszulösen.
- Verbesserte PDF-/GPX-Funktionen und vollständige deutsche/englische
  Übersetzungen.
- Die Berechnungsformeln, Fahrzeug-/Routenpersistenz und Providergrenzen aus
  Beta.16 bleiben unverändert.

### Installation und Kompatibilität

In HACS das Repository als Custom Repository hinzufügen und die reguläre
Stable-Version `v0.1.1` auswählen. Alternativ das Release-ZIP nach
`custom_components/camper_route_planner/` entpacken und Home Assistant danach
neu starten. Eine bereits geöffnete Lovelace-Karte kann einen normalen Browser-
Reload benötigen, damit die versionierte Resource geladen wird.

### Bekannte Einschränkungen

- Keine automatische Tankstellensuche.
- Keine automatischen Dieselpreisabfragen.
- Keine automatische Tankstopp-Optimierung.
- Live-Nakordoni-/Mautdaten und einzelne Exportpfade wurden nicht vollständig
  durch den abschließenden Nutzer-Praxistest abgenommen.
- Externe Navigations-Apps können Routen neu berechnen und Fahrzeugparameter
  ignorieren; GPX bleibt der zuverlässigere Übergabeweg für komplexe Routen.

Keine echten Nakordoni-Anfragen, keine automatische Installation und keine
Änderung produktiver Home-Assistant-Daten sind Bestandteil dieses Releases.

## English

`v0.1.1` is the Stable release based on Beta.16. Existing vehicle profiles,
config entries, saved routes, and GPX data remain compatible; Stable `v0.1.0`
remains available as a rollback version.

### Changes and fixes

- Extended motorhome route planning with traffic and route options, avoidance
  options, ECO routing, and alternative routes.
- Departure and arrival times plus improved map and mobile presentation.
- Vehicle-based fuel planning with fuel level in litres or percent, range
  calculation, and manual fuel-cost estimation.
- A neutral planning note shows required refuelling stops or additional fuel
  demand without triggering automatic refuelling stops.
- Improved PDF/GPX features and complete German/English translations.
- Beta.16 calculation formulas, vehicle/route persistence, and provider
  boundaries remain unchanged.

### Installation and compatibility

In HACS, add the repository as a custom repository and select the regular Stable
version `v0.1.1`. Alternatively, unpack the release ZIP into
`custom_components/camper_route_planner/` and restart Home Assistant. An already
open Lovelace card may need a normal browser reload to load the versioned
resource.

### Known limitations

- No automatic fuel-station search.
- No automatic diesel-price lookup.
- No automatic refuelling-stop optimization.
- Live Nakordoni/toll data and some export paths were not fully accepted in the
  final user practical test.
- External navigation apps may recalculate routes and ignore vehicle
  parameters; GPX remains the more reliable handoff for complex routes.

No live Nakordoni requests, automatic installation, or productive Home Assistant
data changes are part of this release.
