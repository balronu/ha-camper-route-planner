# Camper Route Planner v0.1.0

## Deutsch

Die erste eigenständige Stable-Version von Camper Route Planner ist
veröffentlicht.

- Nakordoni-Motorhome-Routing verwendet den internen Provider
  `nakordoni_motorhome` unter der sichtbaren Auswahl **Nakordoni**.
- **Mock (offline)** bleibt für deterministische Tests verfügbar; es gibt
  keinen automatischen Mock-Fallback bei Providerfehlern.
- Fahrzeugprofile unterstützen mehrere Fahrzeuge, Bearbeiten, Hinzufügen,
  IDs, Tracker-Zuordnungen und Fahrzeugparameter für die Routenanfrage.
- **Keine Änderungen an Fahrzeugen** ist die Standardaktion und schützt
  bestehende Profile bei Provider- oder API-Key-Änderungen.
- Die Lovelace-Karte unterstützt manuelle Routenberechnung, Entfernung,
  Fahrzeit, Karten-/SVG-Darstellung und Fehleranzeigen.
- **Im Navi öffnen** verwendet Apple Maps auf iOS, Google Maps Directions auf
  Android und OpenStreetMap Directions als Desktop-Fallback.
- GPX-Route, GPX-Track und kombinierter GPX-Export bleiben enthalten.

### Installation

In HACS das Repository als Custom Repository hinzufügen und die reguläre
Version `v0.1.0` installieren. Alternativ das Release-ZIP nach
`custom_components/camper_route_planner/` entpacken und die Integration über
**Einstellungen → Geräte & Dienste** einrichten. Danach eine Lovelace-
Ressource mit der Stable-Bundle-URL verwenden oder die automatisch registrierte
Ressource übernehmen.

### Einschränkungen

Externe Navigations-Apps können Routen neu berechnen und Länge, Breite, Höhe,
Gewicht, Achszahl oder Zwischenziele ignorieren. Für komplexe Wohnmobilrouten
ist GPX der vorgesehene Übergabeweg. Der Motorhome-Provider kann beim Anbieter
weiterhin als Beta-Profil geführt werden; Verkehrszeichen und geltende
Vorschriften haben Vorrang. Automatisierte Tests verwenden gemockte APIs und
führen keine echten Nakordoni-Anfragen aus.

## English

The first independent Stable release of Camper Route Planner is published.

- Nakordoni motorhome routing uses the internal `nakordoni_motorhome` provider
  behind the visible **Nakordoni** choice.
- **Mock (offline)** remains available for deterministic tests; provider errors
  never trigger an automatic mock fallback.
- Vehicle profiles support multiple vehicles, editing, adding, stable IDs,
  tracker assignments, and vehicle parameters for routing requests.
- **No changes to vehicles** is the default action and protects existing
  profiles when the provider or API key changes.
- The Lovelace card supports manual route calculation, distance, duration,
  map/SVG rendering, and error states.
- **Open in navigation** uses Apple Maps on iOS, Google Maps Directions on
  Android, and OpenStreetMap Directions as the desktop fallback.
- GPX route, GPX track, and combined GPX export remain available.

### Installation

In HACS, add the repository as a custom repository and install the regular
`v0.1.0` release. Alternatively extract the release ZIP into
`custom_components/camper_route_planner/` and set up the integration through
**Settings → Devices & services**. Then use the Stable bundle URL as a
Lovelace resource or keep the resource registered automatically by the
integration.

### Limitations

External navigation apps may recalculate routes and ignore length, width,
height, weight, axle count, or waypoints. GPX is the intended handoff for
complex motorhome routes. The motorhome provider may still be labeled a beta
profile by the provider; traffic signs and applicable regulations take
precedence. Automated tests use mocked APIs and do not make real Nakordoni
requests.
