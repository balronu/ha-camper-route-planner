# Camper Route Planner v0.1.6-beta.11

## Deutsch

Beta 11 ist eine reine Diagnose-Beta auf Basis von Beta 10. Bei einer
`invalid_response`-Verwerfung bleiben jetzt sichere Transportmetadaten,
Request-ID sowie Feldnamen und JSON-Typen der parserrelevanten Antwort für die
administrative One-shot-Diagnose erhalten. Fehlende oder offensichtlich
ungültige Pflichtfelder werden benannt.

Die eigentliche Routingvalidierung bleibt unverändert strikt. Vollständige
Providerantworten, API-Schlüssel und Authentifizierungsheader werden nicht
gespeichert. POI-Anfragekombinationen und Kartenverhalten aus Beta 10 bleiben
unverändert.

Für die Diagnose ist genau eine bewusst ausgelöste Routenberechnung mit zuvor
aktivierter One-shot-Diagnose vorgesehen. Die Ausgabe darf ausschließlich
über einen vertrauenswürdigen administrativen Supportkanal geteilt werden.

`v0.1.5` bleibt Stable. Es wurden keine produktiven NaKordoni-Anfragen, keine
VM-104-Konfigurationen, keine Zugangsdaten und keine gespeicherten Routen
geändert.

## English

Beta 11 is a diagnostics-only beta based on beta 10. When an
`invalid_response` rejection occurs, the administrative one-shot diagnostic
now retains safe transport metadata, the request ID, and field names and JSON
types for parser-relevant response fields. Missing or obviously invalid
required fields are identified.

The actual routing validation remains strict and unchanged. Complete provider
responses, API keys, and authentication headers are not stored. The beta 10
POI request combinations and map behavior remain unchanged.

The diagnostic workflow requires exactly one deliberate route calculation with
the one-shot diagnostic armed beforehand. Share the output only through a
trusted administrative support channel.

`v0.1.5` remains Stable. No productive NaKordoni requests, VM 104
configuration, credentials, or saved routes were changed.
