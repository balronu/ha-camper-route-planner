# Camper Route Planner v0.1.6-beta.5

## Deutsch

### Kartenzoom und Popup

- Nach einer erfolgreichen Berechnung umfasst die automatische Kartenansicht
  jetzt die vollständige Routengeometrie und alle relevanten Stationsmarker.
- Das Fitten erfolgt nach dem sichtbaren Layout-Zyklus und berücksichtigt damit
  auch Größenänderungen und zuvor verborgene Karten.
- Die Karte kann über „Karte vergrößern“ in einem großen modalen Popup geöffnet
  werden. Das Popup verwendet eine eigene Leaflet-Instanz, zeigt dieselben
  Routendaten, bietet „Gesamte Route anzeigen“, Zoom und Verschieben.
- Escape, Tastaturfokus, Fokus-Rückgabe und die Sperre des Hintergrund-Scrollens
  sind abgedeckt. Öffnen, Schließen und Fitten erzeugen keine Provider-Anfrage.

### Tests und Grenzen

Die Regressionstests decken Kartenfit, mehrere Routengeometrie-Punkte,
gespeicherte-Routen-Kompatibilität, Popup-Lebenszyklus, mobile Darstellung,
Tastaturbedienung, Leaflet-Bereinigung und das Ausbleiben zusätzlicher
Provider-Anfragen ab. v0.1.5 bleibt Stable; diese Version ist eine Beta.

VM 104, Zoe, gespeicherte Routen, Zugangsdaten und produktive NaKordoni-
Anfragen blieben unverändert.

## English

### Map fitting and popup

- After a successful calculation, automatic map fitting now includes the
  complete route geometry and all relevant station markers.
- Fitting is deferred until the visible layout cycle, covering size changes and
  maps that were previously hidden.
- “Enlarge map” opens a large modal popup. It uses a separate Leaflet instance,
  the same route data, “Show entire route”, zoom, and pan controls.
- Escape, keyboard focus, focus return, and background scroll locking are
  covered. Opening, closing, and fitting do not make a provider request.

### Tests and limits

Regression tests cover route fitting, multi-point geometry, saved-route
compatibility, popup lifecycle, mobile rendering, keyboard operation, Leaflet
cleanup, and the absence of additional provider requests. v0.1.5 remains
Stable; this version is a beta.

VM 104, Zoe, saved routes, credentials, and productive NaKordoni requests
were left unchanged.
