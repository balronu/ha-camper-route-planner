# Camper Route Planner v0.1.6-beta.16

## Deutsch

Beta 16 korrigiert den Datenfluss nach dem Laden gespeicherter Routen. Wenn
`route_options` historisch leer ist, werden vorhandene
`metadata.request_options` für die nächste bewusste Berechnung als Fallback
verwendet. Dadurch bleiben gespeicherte POI-Anforderungen erhalten und bereits
geladene POIs erscheinen nach der ersten Neuberechnung ohne einen zweiten
Klick.

Lokale POI-Anzeigeänderungen bewahren Leaflet-Mittelpunkt und Zoom und lösen
keine neue Provideranfrage aus. Kilometerfilter und eigene Abstände werden nur
angezeigt, wenn die jeweilige Kategorie sichtbar ist; die Werte bleiben beim
Aus- und Einschalten erhalten. Historische POIs ohne belastbare
Anforderungsmetadaten bleiben verborgen.

Die optionale NaKordoni-v3-Tankplanung kann im bestehenden Abschnitt
„Kraftstoff & Reichweite“ aktiviert werden. Tankgröße und Verbrauch werden aus
dem ausgewählten Fahrzeugprofil übernommen, der aktuelle Füllstand wird für
den Startfüllstand umgerechnet und nur die Tankreserve wird zusätzlich
angegeben. Ohne Aktivierung bleibt der bisherige Request unverändert. Die
zurückgelieferten Tankstopps und Kosten werden als Schätzungen getrennt von
den allgemeinen Tankstellen dargestellt; ein fehlender oder unvollständiger
Fuel Plan verwirft keine gültige Route.

Dies ist eine Beta-Fehlerkorrektur, kein Stable-Release. `v0.1.5` bleibt Stable.
VM 104 wurde nicht geändert und es wurden keine produktiven NaKordoni-Anfragen
ausgelöst.

## English

Beta 16 fixes the saved-route data flow. When historical `route_options` is
empty, existing `metadata.request_options` are used as the fallback for the
next deliberate calculation. Saved POI request intent is therefore preserved,
and already loaded POIs appear after the first recalculation without a second
click.

Local POI display changes preserve the Leaflet center and zoom and do not make
another provider request. Kilometer filters and custom spacing controls are
shown only while their category is visible; their values are retained when the
category is toggled. Historical POIs without reliable request metadata remain
hidden.

Optional NaKordoni v3 fuel planning can be enabled in the existing “Fuel &
range” section. Tank capacity and consumption come from the selected vehicle
profile, the current fuel level is converted to the request start percentage,
and only the reserve percentage is added. Without activation the existing
request remains unchanged. Returned stops and costs are shown separately as
estimates; a missing or incomplete optional plan does not invalidate a valid
route.

This is a beta bug-fix release, not Stable. `v0.1.5` remains Stable. VM 104
was not changed and no productive NaKordoni requests were made.
