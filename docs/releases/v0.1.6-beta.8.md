# Camper Route Planner v0.1.6-beta.8

## Deutsch

### UI-Korrekturen

- Eine technische Tracker-ID wie `device_tracker.wohnmobil_zoe` wird in der
  Stationsliste nicht mehr als Adresse angezeigt. Ohne aufgelöste Adresse
  erscheint stattdessen „Aktueller Standort Wohnmobil“; eine echte Adresse hat
  Vorrang. Dafür werden keine zusätzlichen Geocoding-Anfragen ausgelöst.
- Ein leeres Ziel wird als „Ziel noch nicht festgelegt“ angezeigt. Gültige
  Koordinaten ohne Adresse zeigen weiterhin „Koordinaten werden verwendet“.
  Unvollständige Stationen können keine Routenberechnung auslösen.
- Beim Laden oder Wechseln gespeicherter Routen passt die normale
  Dashboard-Karte die vollständige gespeicherte Geometrie nach der sichtbaren
  Leaflet-Initialisierung ein. Manuelle Kartenbewegungen werden nicht
  automatisch zurückgesetzt.

### Kompatibilität und Hinweise

- Die Popup-Karte, ihre separate Leaflet-Instanz, Bedienung und Scroll-Sperre
  wurden nicht verändert. Kartenfit und Laden verwenden weiterhin vorhandene
  Routendaten und lösen keine NaKordoni-Anfrage aus.
- Gespeicherte Routen, Fahrzeugprofile, Zoe und VM 104 wurden nicht verändert
  oder verwendet. Nach dem Update ist kein manueller Migrationsschritt nötig.
- v0.1.5 bleibt Stable. Beta 8 ist eine freiwillige Vorabversion; die
  Kartendarstellung hängt weiterhin von der konfigurierten Kartenquelle ab.

## English

### UI corrections

- A technical tracker ID such as `device_tracker.wohnmobil_zoe` is no longer
  rendered as a station address. Without a resolved address the list shows
  “Current motorhome location”; a real address takes precedence. No additional
  geocoding request is made for this display-only fallback.
- An empty destination is shown as “Destination not set yet”. Valid
  coordinates without an address continue to show “Address unavailable –
  coordinates are used”. Incomplete stations cannot start route calculation.
- When loading or switching saved routes, the normal dashboard map fits the
  complete saved geometry after visible Leaflet initialization. Manual map
  movement is not automatically reset.

### Compatibility and notes

- The popup map, its separate Leaflet instance, controls, and scroll lock were
  not changed. Loading and fitting use existing route data and make no
  NaKordoni request.
- Saved routes, vehicle profiles, Zoe, and VM 104 were not changed or used.
  No manual migration step is required after updating.
- v0.1.5 remains Stable. Beta 8 is an optional preview release; map rendering
  still depends on the configured map source.
