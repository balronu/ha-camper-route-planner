# Camper Route Planner v0.1.6-beta.4

## Deutsch

### Neue Stationsliste

- Start, Zwischenziele und Ziel erscheinen in einer kompakten, nummerierten
  Stationsliste; die Listenposition bestimmt die Rolle.
- Jede Station besitzt eine stabile ID. Auch bisheriger Start und Ziel können
  verschoben werden; Adressen, Koordinaten und Metadaten bleiben gemeinsam.
- Bearbeiten öffnet erst bei Bedarf eine kompakte Suche-/Koordinatenmaske.
  Abbrechen verwirft den Entwurf, Übernehmen ändert nur die gewählte Station.
- Zwischenziele werden vor dem Ziel eingefügt, können bearbeitet, verschoben
  und entfernt werden. Unvollständige Stationen werden nicht berechnet.

### Kompatibilität und Tests

Gespeicherte Routen, Fahrzeugprofile, NaKordoni v2/v3, maximal fünf
Zwischenziele, GPX-/PDF-Export, Veraltet-Markierung, Entwicklerdiagnose sowie
optionale Abfahrts- und Ankunftszeiten bleiben über die vorhandene
`origin`/`destination`/`via`-Abbildung kompatibel. v0.1.5 bleibt Stable.

Die neue Stations-E2E-Prüfung deckt Sulzbach/Saar → Badajoz → Lissabon →
Mindelo → Gondifelos, Rollenwechsel, Mehrfachverschiebung, Suche, Abbrechen,
Übernehmen, Hinzufügen, Entfernen, API-Reihenfolge und stabile IDs ab.

VM 104, Zoe, gespeicherte Routen, Zugangsdaten und produktive NaKordoni-
Anfragen blieben unverändert.

## English

### New station list

- Origin, waypoints, and destination are shown in one compact numbered list;
  the list position determines the role.
- Each station has a stable ID. The former origin and destination can also be
  moved, while address, coordinates, and metadata stay together.
- Editing opens a compact search/coordinate form only on demand. Cancel keeps
  the original record; Apply changes only the selected station.
- Waypoints are inserted before the destination and can be edited, moved, or
  removed. Incomplete stations are never submitted for calculation.

### Compatibility and tests

Saved routes, vehicle profiles, NaKordoni v2/v3, the maximum of five
waypoints, GPX/PDF export, stale-result marking, developer diagnostics, and
optional departure/arrival times remain compatible through the existing
`origin`/`destination`/`via` mapping. v0.1.5 remains Stable.

The new station E2E test covers Sulzbach/Saar → Badajoz → Lissabon → Mindelo
→ Gondifelos, role changes, repeated moves, search, cancel, apply, add,
remove, API ordering, and stable IDs.

VM 104, Zoe, saved routes, credentials, and productive NaKordoni requests
were left unchanged.
