# Camper Route Planner v0.1.1-beta.4

## Deutsch

Hotfix für die Phase-6B-Test-Beta nach dem Praxistest von Beta.3.

- Strukturierte Mautdaten bleiben vollständig lokalisiert.
- Bekannte Nakordoni-Hinweise zur fehlenden Emissionsklasse werden verständlich eingeordnet: Euro 6 ist eine Anbieterannahme und keine bestätigte Fahrzeugeigenschaft.
- Unbekannte Anbietertexte werden nicht blind übersetzt, sondern als Originaltext eines Anbieterhinweises gekennzeichnet.
- Keine automatische Euro-6-Einstufung und keine zusätzliche Border-API-Abfrage. Die separate Border-API ist für die konkrete DE → FR → CH-Motorhome-Route nicht belastbar zuordenbar und nutzt ein Heavy-Kontingent.
- Die funktionierende Grenzerkennung aus Beta.3, GPX, Apple Maps, Karten-Lifecycle und einklappbare Karte bleiben erhalten.

## English

Phase-6B hotfix after the Beta.3 field test.

- Structured toll data remains fully localized.
- Known Nakordoni notices about a missing emission class are explained clearly: Euro 6 is a provider assumption, not a confirmed vehicle property.
- Unknown provider text is not blindly translated; it is labelled as original provider text.
- No automatic Euro 6 assignment and no additional Border API request. The separate Border API cannot be reliably matched to the concrete DE → FR → CH motorhome route and uses a heavy quota class.
- Beta.3 border fallback, GPX, Apple Maps, map lifecycle and collapsible-card behavior are preserved.

Install only in a test Home Assistant instance. Stable `v0.1.0` remains unchanged. Phase 6C–6E remain paused pending the next field test.
