# Camper Route Planner v0.1.0-beta.4

## Deutsch

### Fehlerbehebung

- Der installierbare Bundle-Inhalt wird aus `frontend/package.json` gebaut und
  trägt dieselbe Beta-Version wie Manifest, Paket und Cache-URL.
- Die Integration fordert die HA-Abhängigkeit `frontend` an, liefert das
  Bundle über den Static Path `/camper_route_planner/camper-route-planner-card.js`
  aus und registriert die versionierte Extra-JS-URL automatisch.
- Der Static Path wird über Config-Entry-Reloads nicht doppelt registriert;
  die Extra-JS-URL wird beim erneuten Setup idempotent wieder aktiviert.
- Die Karte registriert `camper-route-planner-card` und den visuellen Editor
  idempotent. YAML-Konfiguration, Einzelinstanz-Erkennung, Fahrzeugauswahl,
  Start/Ziel und Mock-Routenberechnung bleiben erhalten.

### Installation

In HACS als **Custom repository** hinzufügen und die Pre-release-Version
`v0.1.0-beta.4` auswählen. Alternativ den Ordner
`custom_components/camper_route_planner/` aus diesem Repository kopieren und
Home Assistant danach neu starten. Bestehende Dashboards werden nicht geändert;
eine manuelle Lovelace-Ressource ist nicht erforderlich.

### Einschränkungen

- Dies ist eine Beta mit deterministischem Mock-Routing; keine geprüfte
  Wohnmobilnavigation.
- Ein echter HACS-UI-Installationslauf und iOS-Safari konnten in der isolierten
  CI-Umgebung nicht ausgeführt werden.
- Es wurden keine Änderungen an VM 104 vorgenommen und keine Nakordoni-Live-
  Aufrufe ausgeführt.

## English

### Fixes

- The installable bundle is built from `frontend/package.json` and uses the
  same beta version in the manifest, package metadata, and cache URL.
- The integration declares the HA `frontend` dependency, serves the bundle at
  `/camper_route_planner/camper-route-planner-card.js`, and registers the
  versioned extra module URL automatically.
- The static path is not registered twice during config-entry reloads; the
  extra module URL is restored idempotently on setup.
- The card and visual editor register idempotently. YAML configuration,
  single-entry discovery, vehicle selection, origin/destination input, and
  mock route calculation remain supported.

### Installation

Add the repository to HACS as a **Custom repository** and select the
pre-release `v0.1.0-beta.4`. Alternatively copy
`custom_components/camper_route_planner/` from this repository and restart
Home Assistant. Existing dashboards are not changed and no manual Lovelace
resource is required.

### Limitations

- This is a beta using deterministic mock routing; it is not verified motorhome
  navigation.
- A real HACS UI installation and iOS Safari run were not available in the
  isolated CI environment.
- VM 104 was not changed and no live Nakordoni calls were made.
