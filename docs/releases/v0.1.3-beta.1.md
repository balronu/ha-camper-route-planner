# Camper Route Planner v0.1.3-beta.1

## Deutsch

Diese Beta ergänzt eine ausdrücklich auslösbare, getrennte Mautschätzung über
NaKordoni API v2, wenn eine tatsächlich berechnete API-v3-Route unvollständige
Mautdaten meldet. Die v3-Route bleibt maßgeblich; die v2-Antwort wird weder in
Entfernung, Fahrzeit noch Mautsumme eingemischt. Bei abweichenden Routen wird
keine gemeinsame Gesamtsumme angezeigt.

Der Routing-Transport serialisiert Aufrufe pro Prozess mit mindestens einer
Sekunde Abstand, verarbeitet begrenzte `503 busy`-Antworten mit
`retry_after` und stellt die sichere Diagnose `X-Route-Source` (`primary` oder
`fallback`), Laufzeit und Versuchszahl bereit. API-Schlüssel und sensible
Header werden nicht in Diagnose oder Artefakte übernommen.

Wohnmobilparameter bleiben strikt: Höhe, Breite, Länge, Gewicht und Achsen
werden übertragen; Lkw-Lenk-/Ruhezeitparameter werden nicht verwendet. Die
bekannte mögliche Überstrenge von Lkw-Verbotsschildern für Wohnmobile bleibt
transparent und wird nicht eigenmächtig rechtlich überschrieben.

Diese Version ist eine Pre-release. Stable `v0.1.2` bleibt die empfohlene
Produktivversion. Es wurden keine produktiven Home-Assistant-Installationen,
Profile, gespeicherten Routen oder API-Schlüssel verändert.

## English

This beta adds an explicit, separate NaKordoni API v2 toll estimate when an
actually calculated API v3 route reports incomplete toll data. The v3 route
remains authoritative; v2 data is never merged into its distance, duration,
or toll total. If route values differ, the UI does not present a combined
total.

The routing transport serializes calls per process with at least one second
between requests, handles bounded `503 busy` responses using `retry_after`,
and exposes safe `X-Route-Source` (`primary` or `fallback`), duration, and
attempt diagnostics. API keys and sensitive headers are excluded from
diagnostics and artifacts.

Motorhome parameters remain strict: height, width, length, weight, and axles
are sent; truck driving/rest-time parameters are not used. The known possible
over-application of truck-prohibition signs to motorhomes remains transparent
and is not overridden with an assumed legal exception.

This is a pre-release. Stable `v0.1.2` remains the production recommendation.
No productive Home Assistant installation, vehicle profile, saved route, or
API key was changed.
