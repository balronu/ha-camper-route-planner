# Camper Route Planner v0.1.0-beta.13

## Deutsch

Beta.13 enthält die Phase-3L-Korrekturen aus dem Praxistest von Beta.12.

### Änderungen und Fehlerbehebungen

- Die vollständige Leaflet-Standard-CSS ist jetzt im Shadow-DOM der Karte
  enthalten. Tile-, Pane- und Map-Positionierung funktionieren dadurch auch
  innerhalb von Home Assistant korrekt.
- Die Kartenkacheln decken den gesamten Kartencontainer ab; die Karte bleibt
  bei Desktop- und Mobilbreiten sowie nach Größenänderungen nutzbar.
- Geoapify-Suchergebnisse erscheinen direkt unter dem jeweiligen Start-, Ziel-
  oder Zwischenziel-Feld statt unterhalb des gesamten Formularrasters.
- Die Auswahl eines Suchergebnisses übernimmt weiterhin Koordinaten und
  aktualisiert die zugehörigen Marker; die Ergebnisliste schließt danach.
- Regressionstests schützen Kachelflächenabdeckung, Shadow-DOM-CSS,
  Suchfeld-Zuordnung, Marker, Resize und Reload.

### Installation und Einschränkungen

Beta.13 ist als GitHub-Pre-release für HACS vorgesehen. Pre-releases müssen in
HACS ausdrücklich aktiviert bzw. ausgewählt werden. Die Release-Prüfung nutzt
isolierte HA-2026.10.1-Fixtures, Mock-Daten und Chromium.

Echte CARTO-, Geoapify- und Nakordoni-Aufrufe wurden nicht durchgeführt.
Produktive Key-Restriktionen, öffentliche Tile-Netzwerkbedingungen, WebKit/iOS
und die Darstellung in einer produktiven Home-Assistant-Instanz bleiben
unbestätigt. VM 104, produktive Config Entries, API-Schlüssel und andere
Integrationen wurden nicht verändert.

## English

Beta.13 contains the Phase 3L fixes from the Beta.12 practical test.

### Changes and fixes

- The complete Leaflet standard stylesheet is now included in the card Shadow
  DOM. Tile, pane, and map positioning therefore also work correctly inside
  Home Assistant.
- Map tiles cover the complete map container and remain usable at desktop and
  mobile widths, including after resizing.
- Geoapify search results now appear directly below the relevant origin,
  destination, or waypoint field instead of below the complete form grid.
- Selecting a search result continues to populate coordinates and update the
  associated markers; the result list closes afterward.
- Regression tests cover tile-area coverage, Shadow DOM CSS, field association,
  markers, resize, and reload.

### Installation and limitations

Beta.13 is intended as a GitHub pre-release for HACS. Explicitly enable or
select pre-releases in HACS. Release validation uses isolated HA-2026.10.1
fixtures, mocked data, and Chromium.

No productive CARTO, Geoapify, or Nakordoni requests were made. Production key
restrictions, public tile-network conditions, WebKit/iOS, and rendering in a
productive Home Assistant instance remain unverified. VM 104, productive
Config Entries, API keys, and other integrations were not changed.
