# Camper Route Planner v0.1.0-beta.18

## Deutsch

Beta.18 veröffentlicht die Phase-3V-Korrekturen für die Lovelace-Interaktion.

### Änderungen und Fehlerbehebungen

- Event-Handler werden nach jedem DOM-Teilrendering erneut gebunden.
- Zielsuche, Geoapify-Treffer-Auswahl und gültige Zielkoordinaten funktionieren
  wieder über die ausgelieferten Buttons.
- Zwischenziele können hinzugefügt, gesucht, ausgewählt, bearbeitet, entfernt
  und umgeordnet werden.
- Der Eingabefokus wird bei der Suche scrollstabil erhalten.
- Leaflet-Instanz, CARTO-Tile-Layer, Marker und Vorschau-Linie bleiben bei
  Änderungen erhalten.
- Source-, Dist- und installierbares HA-Frontend-Bundle sind synchron.

### Installation und Einschränkungen

Beta.18 ist ein GitHub-Pre-release für HACS. Pre-releases müssen in HACS
ausdrücklich aktiviert bzw. ausgewählt werden. Die Prüfung umfasst isolierte
HA-2026.10.1-Fixtures, kontrollierte Mock-Antworten, Chromium Desktop/Touch,
Hassfest, Secret-Scan und alle sechs GitHub-CI-Gates.

Echte CARTO-, Geoapify- und Nakordoni-Aufrufe sowie VM 104 wurden nicht
verwendet. Ein echter WebKit/iOS-Test bleibt offen; der manuelle iPhone-
Praxistest ist erforderlich. Die Integration bleibt deterministisches
Mock-Routing und ist keine geprüfte Wohnmobilnavigation.

## English

Beta.18 publishes the Phase 3V fixes for Lovelace interaction handling.

### Changes and fixes

- Event handlers are rebound after every partial DOM render.
- Destination search, Geoapify result selection, and valid destination
  coordinates work again through the delivered controls.
- Waypoints can be added, searched, selected, edited, removed, and reordered.
- Search preserves input focus without scrolling the page.
- The Leaflet instance, CARTO tile layer, markers, and preview line remain in
  place while points change.
- Source, distribution, and installable HA frontend bundles are synchronized.

### Installation and limitations

Beta.18 is a GitHub pre-release for HACS. Explicitly enable or select
pre-releases in HACS. Validation covers isolated HA 2026.10.1 fixtures,
controlled mock responses, Chromium desktop/touch, Hassfest, secret scanning,
and all six GitHub CI gates.

No productive CARTO, Geoapify, or Nakordoni requests were made, and VM 104 was
not changed. A real WebKit/iOS test remains open; the manual iPhone practical
test is required. The integration still uses deterministic mock routing and
is not verified motorhome navigation.
