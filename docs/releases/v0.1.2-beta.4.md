# Camper Route Planner v0.1.2-beta.4

## Deutsch

Diese Beta korrigiert die Kraftstoffkosten-Datenkette und den Providerstatus
der Lovelace-Karte.

- Manuelle Dieselpreise mit deutschem Komma oder englischem Punkt werden
  unmittelbar als Kosten für den Gesamtverbrauch berechnet.
- `2,16` und `2.16` werden validiert; leere und ungültige Eingaben bleiben
  eindeutig behandelt.
- Manuelle Kraftstoffwerte werden zusätzlich im gespeicherten Routensatz
  abgelegt und beim Laden wiederhergestellt. Alte Routen ohne diese Felder
  bleiben kompatibel.
- Der Kartenkopf normalisiert v2/v3-Provider-Aliase und unterscheidet den
  konfigurierten Provider von der tatsächlich ausgeführten API-Version.
- API v2 wird als `Nakordoni · API v2`, v3 als `Nakordoni · API v3 (Beta)`
  angezeigt; Providerwechsel lösen weiterhin nur die ausdrücklich gestartete
  Routinganfrage aus.

Für die Referenzstrecke 2.474,7 km bei 10,5 l/100 km und 2,16 €/l ergibt sich
eine Gesamtverbrauchs-Kostenschätzung von ca. 561,26 €; der zusätzliche
Kraftstoffbedarf bleibt davon fachlich getrennt. Keine echten Nakordoni-Aufrufe
wurden durchgeführt.

## English

This beta fixes the fuel-cost data chain and the Lovelace provider status.

- Manual diesel prices using a German comma or English dot are calculated
  immediately as total-consumption costs.
- `2,16` and `2.16` are validated; empty and invalid input remains explicit.
- Manual fuel values are now stored with a saved route and restored when it is
  loaded. Older routes without these fields remain compatible.
- The card header normalizes v2/v3 provider aliases and distinguishes the
  configured provider from the API version actually executed.
- API v2 is shown as `Nakordoni · API v2`, v3 as `Nakordoni · API v3 (Beta)`;
  switching providers still causes only an explicitly started route request.

For the reference route of 2,474.7 km at 10.5 l/100 km and €2.16/l, the total
consumption cost is approximately €561.26; additional fuel demand remains a
separate planning value. No real Nakordoni calls were performed.
