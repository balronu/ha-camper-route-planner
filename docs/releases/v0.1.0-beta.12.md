# Camper Route Planner v0.1.0-beta.12

## Deutsch

Beta.12 enthält die Phase-3J-Korrekturen nach dem Praxistest von Beta.11.

### Änderungen und Fehlerbehebungen

- Ausgewählte Geoapify-Suchergebnisse übernehmen Latitude und Longitude jetzt
  zuverlässig in die Koordinatenfelder und aktualisieren die Zielmarkierung.
- GPS-Positionen des ausgewählten Fahrzeug-Trackers werden als Startpunkt
  übernommen. Ungültige `0/0`-Koordinaten werden nicht als Standort akzeptiert.
- Veraltete Eingabefeldwerte können frisch ausgewählte Such- oder Tracker-
  Koordinaten nicht mehr beim Rendern überschreiben.
- CARTO-Kacheln lösen den SVG-Fallback nicht mehr wegen eines einzelnen,
  vorübergehenden Tile-Fehlers aus. Tile-Ladeerfolg, Grace-Period und Timeout
  unterscheiden zwischen nutzbarer Karte und vollständigem Fehlschlag.
- Deutsche und englische Config-Flow-Titel für das Hinzufügen und Bearbeiten
  von Fahrzeugprofilen wurden korrigiert.

### Installation und Einschränkungen

Beta.12 ist als GitHub-Pre-release für HACS vorgesehen. Pre-releases müssen in
HACS ausdrücklich aktiviert bzw. ausgewählt werden. Die Release-Prüfung nutzt
isolierte HA-2026.10.1-Fixtures, Mock-Daten und Chromium.

Echte CARTO-, Geoapify- und Nakordoni-Aufrufe wurden nicht durchgeführt.
Produktive Key-Restriktionen, öffentliche Tile-Netzwerkbedingungen, WebKit/iOS
und die Darstellung in einer produktiven Home-Assistant-Instanz bleiben
unbestätigt. VM 104, produktive Config Entries, API-Schlüssel und andere
Integrationen wurden nicht verändert.

## English

Beta.12 contains the Phase 3J fixes from the Beta.11 practical test.

### Changes and fixes

- Selected Geoapify search results now reliably populate latitude and longitude
  fields and update the destination marker.
- The selected vehicle tracker position is used as the route origin. Invalid
  `0/0` coordinates are not accepted as a location.
- Stale input-field values can no longer overwrite newly selected search or
  tracker coordinates during rendering.
- CARTO tiles no longer trigger the SVG fallback because of one transient tile
  error. Tile success, a grace period, and a timeout distinguish a usable map
  from a complete tile-loading failure.
- German and English Config Flow titles for adding and editing vehicle profiles
  are corrected.

### Installation and limitations

Beta.12 is intended as a GitHub pre-release for HACS. Explicitly enable or
select pre-releases in HACS. Release validation uses isolated HA-2026.10.1
fixtures, mocked data, and Chromium.

No productive CARTO, Geoapify, or Nakordoni requests were made. Production key
restrictions, public tile-network conditions, WebKit/iOS, and rendering in a
productive Home Assistant instance remain unverified. VM 104, productive
Config Entries, API keys, and other integrations were not changed.
