# Camper Route Planner v0.1.6-beta.3

## Deutsch

### Fehlerbehebung

- Bearbeiten, Hinzufügen, Entfernen und Verschieben von Zwischenzielen bewahrt
  die sichtbare Kartenposition stabiler.
- Der Tastaturfokus bleibt bei Maus- und Tastaturbedienung sinnvoll erhalten.
- Die Wiederherstellung ist auf die Route-Planner-Karte begrenzt und verändert
  keine globalen Dashboard-Scrollcontainer.
- Die One-shot-Entwicklerdiagnose aus Beta.2 bleibt bei fehlgeschlagenen
  Berechnungen verfügbar; ein HTTP-504-Timeout wird nicht als
  Fahrzeugbeschränkung interpretiert.

### Kompatibilität und Tests

Diese Beta ist für gezielte Tests vorgesehen. Die PR-Gates für Python,
Frontend, Chromium Desktop/Mobile/Tablet, HA-Fixtures, Hassfest, Quality und
HACS wurden auf dem geprüften Fix bestanden. v0.1.5 bleibt Stable.

VM 104, Zoe, gespeicherte Routen und produktive API-Zugänge wurden nicht
verändert; für die Veröffentlichung wurden keine produktiven NaKordoni-Anfragen
ausgeführt.

## English

### Fixes

- Editing, adding, removing, and moving waypoints preserve the visible card
  position more reliably.
- Keyboard focus remains useful for both mouse and keyboard interaction.
- Restoration is scoped to the route-planner card and does not alter global
  dashboard scroll containers.
- The Beta.2 one-shot developer diagnostic remains available after failed
  calculations; an HTTP 504 timeout is not interpreted as a vehicle restriction.

### Compatibility and tests

This beta is intended for targeted testing. The PR gates for Python, frontend,
Chromium desktop/mobile/tablet, HA fixtures, Hassfest, Quality, and HACS passed
on the reviewed fix. v0.1.5 remains Stable.

VM 104, Zoe, saved routes, and productive API credentials were not changed; no
productive NaKordoni requests were made for this publication.
