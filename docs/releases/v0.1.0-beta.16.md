# Camper Route Planner v0.1.0-beta.16

## Deutsch

Beta.16 veröffentlicht die Phase-3R-Korrekturen für die Geoapify-Zielauswahl
auf iOS und den Leaflet-Kartenlebenszyklus.

### Änderungen und Fehlerbehebungen

- Bei der Auswahl eines Geoapify-Treffers bleibt der bestehende Shadow-DOM
  einschließlich Eingabefeldern erhalten.
- Die bestehende Leaflet-Instanz, der Kartencontainer und der CARTO-Tile-Layer
  bleiben erhalten; nur die Marker werden aktualisiert.
- Wiederholte Zielauswahl erzeugt keine doppelten Marker und keine unnötigen
  neuen Tile-Anfragen.
- iOS-Fokus und Dashboard-Scrollposition bleiben bei der Zielauswahl stabil.
- Verspätete oder abgebrochene Tile-Ereignisse einer alten Karteninstanz können
  die aktuelle Karte nicht mehr fälschlich in den SVG-Fallback versetzen.
- Source-, Dist- und installierbares HA-Frontend-Bundle sind synchron.

### Installation und Einschränkungen

Beta.16 ist ein GitHub-Pre-release für HACS. Pre-releases müssen in HACS
ausdrücklich aktiviert bzw. ausgewählt werden. Die Prüfung umfasst isolierte
HA-2026.10.1-Fixtures, Mock-Daten, Chromium Desktop/Touch und alle sechs
GitHub-CI-Gates.

Echte CARTO-, Geoapify- und Nakordoni-Aufrufe sowie VM 104 wurden nicht
verwendet. Ein echter WebKit/iOS-Test war wegen fehlender Systembibliotheken
nicht ausführbar; der manuelle iPhone-Praxistest bleibt erforderlich. Die
Integration bleibt deterministisches Mock-Routing und ist keine geprüfte
Wohnmobilnavigation.

## English

Beta.16 publishes the Phase 3R fixes for iOS Geoapify target selection and the
Leaflet map lifecycle.

### Changes and fixes

- Selecting a Geoapify result preserves the existing Shadow DOM and input
  elements.
- The existing Leaflet instance, map container, and CARTO tile layer remain in
  place; only markers are updated.
- Repeated target selection does not create duplicate markers or unnecessary
  new tile requests.
- iOS focus and dashboard scroll position remain stable during selection.
- Late or aborted tile events from an old map instance cannot incorrectly
  switch the current map to the SVG fallback.
- Source, distribution, and installable HA frontend bundles are synchronized.

### Installation and limitations

Beta.16 is a GitHub pre-release for HACS. Explicitly enable or select
pre-releases in HACS. Validation covers isolated HA 2026.10.1 fixtures,
mocked data, Chromium desktop/touch, and all six GitHub CI gates.

No productive CARTO, Geoapify, or Nakordoni requests were made, and VM 104 was
not changed. A real WebKit/iOS test could not run because required system
libraries were unavailable; the manual iPhone practical test remains required.
The integration still uses deterministic mock routing and is not verified
motorhome navigation.
