# Camper Route Planner v0.1.1-beta.3

## Deutsch

Hotfix für die Phase-6B-Test-Beta.

- Korrigierte Grenzerkennung für konkrete Nakordoni-Grenzdaten sowie geordnete `countries`-/`country_split`-Antworten.
- Ungeordnete Länderlisten werden nicht mehr künstlich in Grenzfolgen umgewandelt.
- Abgeleitete Grenzübertritte enthalten weder erfundene Namen, Koordinaten noch Wartezeiten.
- Maut-Systeme und Statuswerte werden in Deutsch und Englisch lokalisiert.
- Die optionale Emissionsklasse wird nur bei expliziter Profilangabe an Nakordoni übergeben; fehlende Angaben werden als unsichere Tarifgrundlage gekennzeichnet.
- Bestehende GPX-, Apple-Maps-, Karten- und manuelle-Berechnungspfade bleiben unverändert.

Vignetten-Detailpreise werden in dieser Beta nicht separat abgefragt. Die im Routing gelieferten Maut-/Vignetteninformationen werden ohne zusätzliche Hintergrundanfragen angezeigt.

## English

Hotfix for the Phase 6B test beta.

- Fixed border detection for concrete Nakordoni border data and ordered `countries`/`country_split` responses.
- Unordered country maps are no longer turned into a fabricated border sequence.
- Inferred crossings contain no fabricated names, coordinates, or wait times.
- Toll systems and status values are localized in German and English.
- The optional emission class is sent to Nakordoni only when explicitly configured; missing data is marked as an uncertain tariff basis.
- Existing GPX, Apple Maps, map, and manual-calculation paths remain unchanged.

Separate vignette price details are not queried in this beta. Toll/vignette information already present in the routing response is displayed without additional background requests.

Install only in a test Home Assistant instance. Do not install automatically in production. Stable `v0.1.0` remains unchanged.
