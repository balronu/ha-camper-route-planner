# Camper Route Planner v0.1.2-beta.2

## Deutsch

Diese Beta korrigiert die geplante Zeitübergabe und macht die tatsächlich
ausgeführte NaKordoni-API-Version sichtbar.

- `datetime-local`-Werte werden im Browser-Zeitzonen-Kontext mit explizitem
  ISO-8601-UTC-Offset an das Backend übergeben.
- Sommer-/Winterzeit wird über die lokale Zeitzonenregel des Browsers
  berücksichtigt; nicht existente Zeiten während der Zeitumstellung werden
  verständlich abgewiesen.
- Bereits gespeicherte Zeitwerte ohne Offset bleiben lesbar und werden bei
  einer neuen Berechnung sicher normalisiert.
- Die Ergebnisanzeige unterscheidet jetzt `Nakordoni · API v2` und
  `Nakordoni · API v3 (Beta)` anhand der tatsächlich normalisierten Antwort.
- Keine echten NaKordoni-Aufrufe wurden für diese Veröffentlichung ausgeführt.

Stable `v0.1.1`, bestehende v2-Config-Entries, VM 104, HACS, Fahrzeugprofile
und gespeicherte Routen bleiben unverändert. Die v3-Beta ist weiterhin keine
Garantie für rechtliche oder praktische Befahrbarkeit.

## English

This beta fixes planned-time serialization and makes the executed NaKordoni
API version visible.

- `datetime-local` values are sent with an explicit ISO-8601 offset derived
  from the browser's local timezone.
- Daylight-saving rules are applied by the local timezone; nonexistent times
  during a clock change are rejected with a clear validation message.
- Previously stored offset-less times remain readable and are normalized when
  a new calculation is requested.
- The result display distinguishes `Nakordoni · API v2` and
  `Nakordoni · API v3 (Beta)` from the normalized response metadata.
- No real NaKordoni calls were performed for this publication.

Stable `v0.1.1`, existing v2 config entries, VM 104, HACS, vehicle profiles,
and saved routes remain unchanged. The v3 beta is not a guarantee of legal or
practical route passability.
