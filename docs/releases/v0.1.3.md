# Camper Route Planner v0.1.3 Stable

## Deutsch

`v0.1.3` ist die geprüfte Stable-Version für Home Assistant.

### Enthalten

- Lokalisierte Grenzübergänge mit ausgeschriebenen Länderbezeichnungen und
  transparenter Anzeige fehlender Wartezeitdaten.
- Native, flüchtige HA-Diagnose der tatsächlich ausgeführten Routingantworten
  ohne API-Schlüssel, vollständige Header oder personenbezogene Standortdaten.
- Getrennte API-v2-/v3-Adapter und nachvollziehbare Mautdatenqualität.
- Kraftstoffkosten, gespeicherte Routen sowie GPX-/PDF-Export bleiben erhalten.
- Der praktische Portugal-Test mit API v3 lieferte `primary`, HTTP 200,
  `complete=true` und 250,24 € Gesamtmaut.

### Bekannte Einschränkung

Die ETA bleibt beim getesteten Wohnmobilprofil konservativ bei ungefähr
90 km/h. Die schriftliche NaKordoni-Bestätigung zur deutschen 100-km/h-Regel
wird dokumentiert, aber die ETA wird nicht künstlich korrigiert. Verkehrszeichen
und geltende Vorschriften haben Vorrang.

### Installation und Rückfall

Installation über HACS als Custom Repository oder manuell nach
`custom_components/camper_route_planner/`, anschließend Einrichtung über
**Einstellungen → Geräte & Dienste**. Es gibt keine Storage- oder
Datenbankmigration. Gespeicherte Routen und Config Entries bleiben erhalten;
die flüchtige letzte Diagnose wird bei einem Neustart verworfen. Ein Rückfall
auf `v0.1.2` ist über dessen unveränderten Tag möglich und wurde nicht auf
einem Produktivsystem ausgeführt.

## English

`v0.1.3` is the verified Stable release for Home Assistant.

### Included

- Localized border crossings with full country names and transparent handling
  of missing waiting-time data.
- Native volatile Home Assistant diagnostics for the actually executed routing
  response, without API keys, complete headers, or personal location data.
- Separate API v2/v3 adapters with explicit toll-data quality.
- Fuel costs, saved routes, and GPX/PDF export remain available.
- The practical Portugal test with API v3 returned `primary`, HTTP 200,
  `complete=true`, and EUR 250.24 total tolls.

### Known limitation

ETA remains conservative at around 90 km/h for the tested motorhome profile.
NaKordoni's written confirmation of the German 100 km/h rule is documented,
but ETA is not artificially corrected. Traffic signs and applicable rules take
precedence.

### Installation and rollback

Install through HACS as a custom repository or copy to
`custom_components/camper_route_planner/`, then configure it under
**Settings → Devices & services**. There is no storage or database migration.
Saved routes and Config Entries remain intact; volatile last-run diagnostics
are discarded on restart. Rollback is possible via the unchanged `v0.1.2` tag
and was not performed on a production system.
