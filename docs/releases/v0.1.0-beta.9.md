# Camper Route Planner v0.1.0-beta.9

## Deutsch

Beta.9 erweitert den Camper Route Planner um eine dauerhaft sichtbare
interaktive Karte und Geoapify-gestützte Adressfunktionen.

### Änderungen

- Karte ohne vorherige Routenberechnung sichtbar
- GPS-Startpunkt über den Tracker des ausgewählten Fahrzeugs
- fahrzeugspezifische Trackerzuordnung; Zoe verwendet standardmäßig
  `device_tracker.wohnmobil_zoe`
- Geoapify-Adresssuche und Reverse Geocoding über das Home-Assistant-Backend
- Adressen für GPS-Punkte, Kartenpunkte und verschobene Marker
- Caching, Debouncing, Rate-Limiting und Koordinaten-Fallback
- mobile Bedienung sowie deutsche und englische Oberfläche
- bestehender GPX-Export, Routenspeicherung und Routingvertrag erhalten

### Installation und Einschränkungen

Beta.9 ist als GitHub-Pre-release für HACS vorgesehen. Für die Adresssuche
muss ein Geoapify-API-Key im Options-Flow hinterlegt werden. Der Schlüssel
bleibt im Backend und wird nicht an das Frontend übertragen. Ohne Schlüssel
bleiben Karte, GPS und manuelle Koordinaten nutzbar.

Geoapify-Live-Aufrufe, produktives Nakordoni-Routing und die Darstellung in
einer produktiven Home-Assistant-Instanz wurden nicht geprüft. Nach der
Installation muss die Pre-release-Version in HACS ausdrücklich ausgewählt
werden. VM 104 wurde nicht verändert.

## English

Beta.9 adds an always-visible interactive map and Geoapify-backed address
features to Camper Route Planner.

### Changes

- map visible before any route calculation
- GPS origin from the selected vehicle tracker
- per-vehicle tracker assignment; Zoe defaults to
  `device_tracker.wohnmobil_zoe`
- Geoapify address search and reverse geocoding through the Home Assistant
  backend
- addresses for GPS points, map points, and dragged markers
- caching, debouncing, rate limiting, and coordinate fallback
- improved mobile interaction and German/English UI
- existing GPX export, route storage, and routing contract retained

### Installation and limitations

Beta.9 is published as a GitHub pre-release intended for HACS. Address search
requires a Geoapify API key configured in the Options Flow. The key remains in
the backend and is never sent to the frontend. Maps, GPS, and manual
coordinates remain available without a key.

Live Geoapify calls, productive Nakordoni routing, and rendering in a
productive Home Assistant instance were not validated. After installation,
select the pre-release explicitly in HACS. VM 104 was not changed.
