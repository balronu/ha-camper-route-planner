# Camper Route Planner v0.1.0-beta.15

## Deutsch

Beta.15 veröffentlicht die Phase-3P-Korrekturen für iOS-Adresssuche und
Adressstatus.

### Änderungen und Fehlerbehebungen

- Geoapify-Suchergebnisse aktualisieren nur noch die Vorschlagsliste. Das
  Eingabefeld, der Fokus, der Cursor, die iOS-Tastatur und die Dashboard-
  Scrollposition bleiben während der Eingabe erhalten.
- Veraltete asynchrone Suchantworten werden verworfen.
- Ausgewählte Adresslabels werden als gültige Adresse gespeichert und bleiben
  sichtbar, wenn Reverse-Geocoding keinen nutzbaren Treffer liefert.
- Die Leaflet-Karte bleibt nach Suche, Tastatur-/Viewport-Resize und gültigen
  CARTO-Tile-Antworten aktiv; HTTP-Fehler und Timeouts verwenden weiterhin den
  vorgesehenen SVG-Fallback.
- Source-, Dist- und installierbares HA-Bundle sind synchron.

### Installation und Einschränkungen

Beta.15 ist ein GitHub-Pre-release für HACS. Pre-releases müssen in HACS
ausdrücklich aktiviert bzw. ausgewählt werden. Die Prüfung nutzt isolierte
HA-2026.10.1-Fixtures, Mock-Daten, Chromium Desktop/Mobile und die sechs
GitHub-CI-Gates.

Echte CARTO-, Geoapify- und Nakordoni-Aufrufe sowie VM 104 wurden nicht
verwendet. WebKit/iOS konnte in der CI-Umgebung wegen fehlender
Systembibliotheken nicht ausgeführt werden; der manuelle iPhone-Praxistest
steht noch aus. Die Integration bleibt deterministisches Mock-Routing und ist
keine geprüfte Wohnmobilnavigation.

## English

Beta.15 publishes the Phase 3P fixes for iOS address search and address
status.

### Changes and fixes

- Geoapify responses now update only the suggestion list. The input element,
  focus, cursor, iOS keyboard, and dashboard scroll position remain stable
  while typing.
- Stale asynchronous search responses are discarded.
- Selected address labels are stored as the address and remain visible when
  reverse geocoding returns no usable result.
- The Leaflet map remains active after searching, keyboard/viewport resize,
  and successful CARTO tile responses; HTTP errors and timeouts retain the
  intended SVG fallback.
- Source, distribution, and installable HA bundles are synchronized.

### Installation and limitations

Beta.15 is a GitHub pre-release for HACS. Explicitly enable or select
pre-releases in HACS. Validation uses isolated HA 2026.10.1 fixtures, mocked
data, Chromium desktop/mobile, and all six GitHub CI gates.

No productive CARTO, Geoapify, or Nakordoni requests were made, and VM 104 was
not changed. WebKit/iOS could not run in the CI environment because required
system libraries were unavailable; the manual iPhone practical test remains
pending. The integration still uses deterministic mock routing and is not
verified motorhome navigation.
