# Camper Route Planner v0.1.3-beta.3

## Deutsch

Beta.3 ergänzt native Home-Assistant-Diagnostik für den Config Entry. Nach
einer ausdrücklich gestarteten Route werden ausschließlich flüchtig im
Arbeitsspeicher gehalten:

- ausgeführte API-Version und `source_api`
- Routingquelle `primary`/`fallback`
- HTTP-Status, Antwortdauer und Retry-Anzahl
- `tolls.complete`, `total_eur` und bereinigte Länderwerte
- getrennte v2-/v3-Aufrufzähler und Fehlerstatus

Die Diagnose löst keine Anfrage aus, speichert keine API-Schlüssel, Tokens,
vollständigen Header oder Standortkoordinaten und wird beim Neustart verworfen.
Eine optionale v2-Mautschätzung bleibt von der v3-Route getrennt und wird nur
nach ausdrücklicher Nutzeraktion ausgeführt.

**Praxistest:** Beta.3 über HACS auswählen/installieren, Home Assistant falls
erforderlich nach der Installation neu starten, die bekannte Portugal-Route
mit v3 ausdrücklich neu berechnen und anschließend die Diagnose des Config
Entry herunterladen. `tolls.complete` und `X-Route-Source` sind mit der
Kartendarstellung zu vergleichen. Keine v2-Schätzung auslösen, wenn nur die
v3-Antwort geprüft werden soll.

Stable `v0.1.2` bleibt unverändert; diese Beta ist kein Stable-Release.

## English

Beta.3 adds native Home Assistant diagnostics for the config entry. After an
explicitly started route, the integration keeps only an in-memory snapshot of:

- the executed API version and `source_api`
- `primary`/`fallback` routing source
- HTTP status, response duration, and retry count
- `tolls.complete`, `total_eur`, and sanitized country values
- separate v2/v3 call counters and error status

Diagnostics do not trigger a request, store API keys, tokens, full headers, or
location coordinates, and are discarded on restart. An optional v2 toll
estimate remains separate from the v3 route and runs only after an explicit
user action.

**Practical test:** select/install Beta.3 through HACS, restart Home Assistant
after installation if required, explicitly recalculate the known Portugal
route with v3, and download the config-entry diagnostics. Compare
`tolls.complete` and `X-Route-Source` with the card display. Do not request the
v2 estimate when validating only the v3 response.

Stable `v0.1.2` remains unchanged; this is not a Stable release.
