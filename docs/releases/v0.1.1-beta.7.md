# Camper Route Planner v0.1.1-beta.7

## Deutsch

### Änderungen

- Das optionale Verbrauchsfeld verwendet jetzt einen sichtbaren Home-Assistant-`NumberSelector` mit 0,1–100 l/100 km und Schrittweite 0,1. Leere Werte bleiben `None`; bestehende Profil-IDs, Werte und Tracker werden nicht migriert oder zurückgesetzt. Dezimalkommas werden vor der lokalen Validierung normalisiert.
- Der PDF-Export erzeugt immer einen normalen Browser-Download. `navigator.share()` wird für den PDF-Pfad nicht mehr aufgerufen. Die Object-URL wird sicher freigegeben. Der Dateiname enthält ausschließlich den bereinigten Fahrzeugnamen und das aktuelle Datum, niemals Routenziele oder Koordinaten.
- Nakordoni verwendet beim Runtime-Aufbau einen `aiohttp.ClientTimeout` mit 10 Sekunden Connect-Limit und 60 Sekunden Gesamtlimit. Es gibt weiterhin keinen automatischen Retry; Zeitüberschreitungen werden als nicht bestätigter Kontingentverbrauch behandelt.
- Erfolgreiche identische Routen werden fünf Minuten in einem begrenzten In-Memory-Cache mit maximal acht Einträgen gehalten. Fehler und Timeouts werden nicht gecacht. `Neu berechnen` umgeht den Cache ausdrücklich. Cache-Treffer zeigen an, dass Grenzwartezeiten und Mautdaten veraltet sein können.

### Kompatibilität und Grenzen

- Stable `v0.1.0` bleibt die Rückfallbasis; diese Version ist ein Pre-release.
- Es werden keine Home-Assistant-Datenbanken, API-Schlüssel, Dashboards, HACS-Installationen oder produktiven Systeme geändert.
- Ein Windows- und iPhone/iPad-Praxistest bleibt erforderlich. Auf iOS hängt das Öffnen/Speichern vom Browser/WebView und dessen Download-Unterstützung ab.

## English

### Changes

- The optional consumption field now uses a visible Home Assistant `NumberSelector` from 0.1 to 100 l/100 km with a 0.1 step. Blank values remain `None`; existing profile IDs, values, and trackers are not migrated or reset. Decimal commas are normalized before local validation.
- PDF export always performs a normal browser download. `navigator.share()` is no longer called from the PDF path. Object URLs are released safely. The filename contains only the sanitized vehicle name and current date, never route destinations or coordinates.
- Nakordoni uses an `aiohttp.ClientTimeout` with a 10-second connect limit and 60-second total limit during runtime assembly. There is still no automatic retry; timeouts are not presented as confirmed free quota usage.
- Successful identical routes are kept for five minutes in a bounded in-memory cache of at most eight entries. Errors and timeouts are not cached. `Recalculate` explicitly bypasses the cache. Cache hits indicate that border waits and toll data may be stale.

### Compatibility and limitations

- Stable `v0.1.0` remains the rollback baseline; this version is a pre-release.
- No Home Assistant databases, API keys, dashboards, HACS installations, or productive systems are changed.
- A Windows and iPhone/iPad practical test is still required. On iOS, opening/saving depends on browser/WebView download support.
