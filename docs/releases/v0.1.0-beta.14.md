# Camper Route Planner v0.1.0-beta.14

## Deutsch

Beta.14 veröffentlicht den CSS-Fix aus Phase 3O für die Leaflet-Karte.

### Änderungen und Fehlerbehebungen

- Der CSS-Selektor für das SVG-Fallback ist auf das direkte Fallback-SVG
  (`.crp-map > svg`) begrenzt.
- Leaflets internes `svg.leaflet-attribution-flag` wird nicht mehr von der
  Fallback-Regel erfasst und behält seine intrinsische Größe.
- Das violett/gelbe Rechteck über der Karte wird dadurch verhindert, ohne die
  Leaflet-Tile-, Pane-, Marker- oder Attributions-CSS zu verändern.
- Ein Chromium-Regresstest prüft die Größe und die Zuordnung des Attribution-
  Flags; Source-, Dist- und installierbares HA-Bundle bleiben synchron.

### Installation und Einschränkungen

Beta.14 ist ein GitHub-Pre-release für HACS. Pre-releases müssen in HACS
ausdrücklich aktiviert bzw. ausgewählt werden. Die Release-Prüfung nutzt
isolierte HA-Fixtures, Mock-Daten und Chromium.

Der manuelle Praxistest der Karte steht noch aus. Echte CARTO-, Geoapify- und
Nakordoni-Aufrufe wurden nicht durchgeführt; WebKit/iOS und die Darstellung in
einer produktiven Home-Assistant-Instanz bleiben unbestätigt. Der separate
Marker-Asset-Nebenbefund ist nicht Bestandteil dieses Releases. VM 104,
produktive Config Entries, API-Schlüssel und andere Integrationen wurden nicht
verändert.

## English

Beta.14 publishes the Phase 3O CSS fix for the Leaflet map.

### Changes and fixes

- The SVG fallback selector is scoped to the direct fallback SVG
  (`.crp-map > svg`).
- Leaflet's internal `svg.leaflet-attribution-flag` is no longer matched by
  the fallback rule and keeps its intrinsic size.
- This prevents the violet/yellow rectangle over the map without changing the
  Leaflet tile, pane, marker, or attribution CSS.
- A Chromium regression test checks the attribution flag size and ownership;
  the source, distribution, and installable HA bundles remain synchronized.

### Installation and limitations

Beta.14 is a GitHub pre-release for HACS. Explicitly enable or select
pre-releases in HACS. Release validation uses isolated HA fixtures, mocked data,
and Chromium.

The manual practical test of the card is still pending. No productive CARTO,
Geoapify, or Nakordoni requests were made; WebKit/iOS and rendering in a
productive Home Assistant instance remain unverified. The separate marker-asset
side finding is not included in this release. VM 104, productive Config Entries,
API keys, and other integrations were not changed.
