# Camper Route Planner v0.1.3-beta.2

## Deutsch

Diese Beta korrigiert die Nachvollziehbarkeit der Mautdarstellung. Mautdaten
tragen jetzt ihre tatsächliche API-Quelle (`v2` oder `v3`) und eine separate
v2-Schätzung bleibt sichtbar von der v3-Route getrennt. Die Länderanzeige
unterstützt die von der Routingstrecke gelieferten europäischen ISO-Codes,
unbekannte Codes bleiben unverändert erhalten.

Unvollständige v3-Daten werden ausdrücklich als unvollständig angezeigt. Eine
optionale v2-Abfrage wird weiterhin nur durch die Nutzeraktion ausgelöst und
nicht beim Laden oder Rendern im Hintergrund gestartet. Durchschnittliche
Netzpreise werden verständlich erläutert; die Original-Tariftexte bleiben in
den technischen Details nachvollziehbar.

Bekannte Einschränkung: NaKordoni kann bei einzelnen Ländern unvollständige
Tarifdaten liefern. Die v2-Ausgabe ist in diesem Fall eine separate Schätzung
und keine verbindliche Gebühr oder v3-Gesamtsumme.

## English

This beta makes toll provenance explicit. Toll data now carries its actual API
source (`v2` or `v3`), while a separate v2 estimate remains visibly distinct
from the v3 route. Country rendering supports the European ISO codes returned
by the routing service and preserves unknown codes unchanged.

Incomplete v3 data is labelled as incomplete. An optional v2 request is still
started only by an explicit user action; loading or rendering a route does not
trigger a background request. Average network prices are explained in user
friendly language, while original tariff text remains available in technical
details.

Known limitation: NaKordoni may have incomplete tariff coverage for some
countries. In that case the v2 result is a separate estimate, not a binding
charge or a v3 total.
