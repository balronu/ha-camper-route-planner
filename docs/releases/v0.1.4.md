# Camper Route Planner v0.1.4 Stable

## Deutsch

### Änderungen

- Gespeicherte Routen übernehmen Start, Ziel und Zwischenziele wieder mit den
  vorhandenen Koordinaten; alte Koordinaten-Entwürfe überschreiben geladene
  Werte nicht.
- Optionale `depart_at`- und `arrive_at`-Werte werden ohne gesetzte Zeit nicht
  als `None` übertragen. Vorhandene gültige Zeiten bleiben erhalten.
- Nach einer fehlgeschlagenen Neuberechnung werden alte Routenergebnisse als
  veraltet gekennzeichnet und nicht als neues Ergebnis dargestellt.
- Die Request-Diagnose ist standardmäßig deaktiviert, nur für Administratoren
  aktivierbar und gilt mit einem kurzlebigen Token genau für einen Backend-
  Berechnungsversuch.
- Native Home-Assistant-Diagnostics enthalten keine Request-Koordinaten,
  Waypoints, sensiblen Requestdaten, Zugangsdaten oder Authentifizierungs-
  Header. Diagnose-Snapshots werden nach dem einmaligen Abruf nicht im Backend
  behalten.
- Die Diagnoseansicht bietet „Diagnose kopieren“ sowie bei nicht verfügbarer
  Zwischenablage ein manuell markierbares Textfeld.

### Kompatibilität und Installation

- Bestehende gespeicherte Routen und Fahrzeugprofile werden ohne Migration
  weiterverwendet.
- Die Installation erfolgt als HACS-Custom-Integration oder manuell über das
  Release-Asset. Bestehende Dashboards werden nicht automatisch verändert.
- Vor einem Versionswechsel sollte ein Home-Assistant-Backup erstellt werden.
- Rollback: in HACS ausdrücklich Stable `v0.1.3` auswählen oder das
  unveränderte Release-Asset von `v0.1.3` installieren. Beta-/Main-Versionen
  nicht als Rollback verwenden.
- Die Diagnose-Kopierfunktion wurde in Chromium geprüft; bei nicht verfügbarer
  Browser-/App-Zwischenablage steht der manuelle Fallback zur Verfügung.

## English

### Changes

- Saved routes preserve the existing coordinates for origin, destination, and
  waypoints; old coordinate drafts no longer overwrite loaded values.
- Optional `depart_at` and `arrive_at` values are omitted when unset instead of
  being sent as `None`. Valid existing times remain intact.
- After a failed recalculation, old route results are marked stale and are not
  presented as a new result.
- Request diagnostics are disabled by default, restricted to administrators,
  and use a short-lived token for exactly one backend calculation attempt.
- Native Home Assistant diagnostics contain no request coordinates, waypoints,
  sensitive request data, credentials, or authentication headers. Request
  snapshots are not retained in the backend after the one-time retrieval.
- The diagnostic view provides “Copy diagnostics” and a manually selectable
  fallback when the browser/app clipboard is unavailable.

### Compatibility and installation

- Existing saved routes and vehicle profiles continue without migration.
- Install as a HACS custom integration or manually from the release asset.
  Existing dashboards are not changed automatically.
- Create a Home Assistant backup before changing versions.
- Rollback: explicitly select Stable `v0.1.3` in HACS or install its unchanged
  release asset. Do not use a beta or main branch as the rollback target.
- The copy feature was tested in Chromium; the manual fallback remains
  available where a browser/app clipboard is unavailable.
