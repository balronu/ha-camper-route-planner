# Camper Route Planner v0.1.2-beta.1

## Deutsch

Diese Beta bereitet die kontrollierte NaKordoni-v3-Erprobung vor.

- Explizite Provider-Auswahl `Nakordoni v3 (Beta)`; bestehende Config Entries
  bleiben unverändert beim bisherigen v2-Provider.
- Strikte Motorhome-Parameter- und v3-Response-Prüfung bleibt aktiv.
- Neue Admin-WebSocket-Diagnose für eine manuelle, einmalige Account-/Usage-
  Abfrage. Sie führt keine Routingberechnung aus, verwendet keine Retries und
  gibt keine Geheimnisse oder vollständigen Header zurück.
- v3 bleibt Beta und ist nicht als sichere Befahrbarkeitsgarantie zu verstehen.

Die echte Account-/Usage-Abfrage und v2/v3-Routingvergleiche wurden nicht in
dieser Veröffentlichung ausgeführt. VM 104, HACS, Stable `v0.1.1`, Fahrzeug-
profile und gespeicherte Routen bleiben unverändert. Vor der Praxisprüfung
müssen die API-Freischaltung, das Kontingent und die tatsächliche Antwort-
semantik kontrolliert bestätigt werden.

## English

This beta prepares the controlled NaKordoni v3 evaluation.

- Explicit `Nakordoni v3 (Beta)` provider selection; existing config entries
  remain on the existing v2 provider.
- Strict motorhome parameter and v3 response validation remains enabled.
- New admin-only WebSocket diagnostic for one manual account/usage check. It
  performs no routing calculation, has no retries, and returns no secrets or
  complete headers.
- v3 remains beta and is not a guarantee that a route is safe to drive.

The real account/usage request and v2/v3 route comparisons were not executed
as part of this publication. VM 104, HACS, Stable `v0.1.1`, vehicle profiles,
and saved routes remain unchanged. API enablement, quota, and response
semantics must be confirmed before practical testing.
