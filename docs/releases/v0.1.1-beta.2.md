# Camper Route Planner v0.1.1-beta.2

## Deutsch

Phase 6B ergänzt die Grenz- und Mautinformationen aus der bestehenden Nakordoni-Motorhome-Routing-Antwort.

- Erkannte Grenzübergänge mit Richtung, Name, Koordinaten und Datenstand.
- Wartezeit wird nur angezeigt, wenn Nakordoni einen Wert liefert; fehlende Werte bleiben ausdrücklich unbestimmt.
- Länder- und Qualitätsinformationen werden aus der Antwort übernommen.
- Motorhome-spezifische Mautsumme, Aufteilung nach Ländern sowie bepreiste Brücken/Tunnel werden angezeigt.
- Grenzübergänge erhalten auf der Leaflet-Karte Marker, sofern Koordinaten geliefert werden.
- Keine zusätzlichen Nakordoni-Anfragen nach der Berechnung, beim Aufklappen, Export oder Öffnen der Navigation.
- Die einklappbare Karte, GPX-Exporte, Navigation und bestehende Fahrzeugdaten bleiben erhalten.

Die API-Fähigkeitsmatrix steht in `docs/NAKORDONI-API-CAPABILITY-MATRIX.md`. Es wurden keine Live-Nakordoni-Anfragen ausgeführt. Stable `v0.1.0` bleibt unverändert; es wird keine Stable-Version veröffentlicht.

## English

Phase 6B adds border and toll information from the existing Nakordoni motorhome routing response.

- Detected border crossings with direction, name, coordinates and data timestamp.
- Wait time is shown only when Nakordoni supplies a value; missing values remain explicitly unknown.
- Country and data-quality information is preserved from the response.
- Motorhome-specific toll total, per-country breakdown and priced bridges/tunnels are displayed.
- Border crossings receive Leaflet markers when coordinates are supplied.
- No additional Nakordoni requests after calculation, on expand/collapse, GPX export or navigation handoff.
- The collapsible card, GPX exports, navigation and existing vehicle data remain intact.

See `docs/NAKORDONI-API-CAPABILITY-MATRIX.md` for the capability matrix. No live Nakordoni requests were made. Stable `v0.1.0` remains unchanged; no Stable release is published.

### Test instructions / Testhinweise

Install this pre-release only in a test Home Assistant instance. Calculate a route crossing one or more borders and verify direction, missing-data handling, toll coverage and map markers. Do not install it automatically into production.
