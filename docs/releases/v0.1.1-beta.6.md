# Camper Route Planner v0.1.1-beta.6

## Deutsch

- Fahrzeugprofile können optional Euro-Schadstoffklasse, CO₂-Klasse, Erstzulassung und Durchschnittsverbrauch speichern.
- Nakordoni erhält weiterhin nur dokumentierte Routingparameter; CO₂-Klasse, Erstzulassung und Verbrauch werden lokal für PDF und Profilinformationen gehalten.
- Neuer clientseitiger PDF-Reiseplanexport für eine bereits berechnete Route mit A4-Seiten, Fahrzeug-, Routen-, Grenz- und Mautdaten sowie lokaler Geometrieübersicht.
- Keine zusätzliche Nakordoni-, Karten- oder PDF-Service-Anfrage beim Export.
- Bestehende Profile, IDs, Tracker, Maße, Gewichte, gespeicherte Routen, GPX und Navigation bleiben erhalten.

Dies ist eine Test-Beta. Stable `v0.1.0` bleibt die Rückfallbasis. Kein automatisches Update und keine Migration sind erforderlich. Ein iPhone-/VM104-Praxistest ist vor dieser Veröffentlichung nicht durchgeführt.

## English

- Vehicle profiles can optionally store Euro emission class, CO2 class, first registration, and average consumption.
- Nakordoni still receives only documented routing parameters; CO2 class, first registration, and consumption remain local for the profile and PDF.
- New client-side PDF travel-plan export for an already calculated route with A4 pages, vehicle, route, border, and toll data plus a local geometry overview.
- No additional Nakordoni, map, or PDF-service request is made during export.
- Existing profiles, IDs, trackers, dimensions, weights, saved routes, GPX, and navigation are preserved.

This is a test beta. Stable `v0.1.0` remains the rollback baseline. No automatic update or migration is required. An iPhone/VM104 practical test was not performed before publication.
