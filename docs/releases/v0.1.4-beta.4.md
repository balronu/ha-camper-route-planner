# Camper Route Planner v0.1.4-beta.4

## Deutsch

### Datenschutz und Diagnose

- Native Home-Assistant-Diagnostics enthalten keine Request-Koordinaten,
  Waypoints, Fahrzeug-Requestdaten, Zugangsdaten oder Header.
- Die gezielte Diagnose bleibt standardmäßig deaktiviert und erfordert eine
  Administratoraktion.
- Ein kurzlebiger Token gilt für genau einen Backend-Berechnungsversuch und
  wird vor parallelen oder nachfolgenden Versuchen verbraucht.
- Erfolgreiche und fehlgeschlagene Versuche hinterlassen keinen Request-
  Diagnose-Snapshot im Backend.
- Die angezeigte bereinigte Diagnose kann ohne weiteren API-Aufruf kopiert
  werden; bei nicht verfügbarer Zwischenablage steht ein manuell markierbares
  Textfeld bereit.

### Kompatibilität und Einschränkungen

- Die Koordinatenkorrektur aus Beta.2 und die optionalen Zeitfelder aus Beta.3
  bleiben erhalten.
- Gespeicherte Routen, Fahrzeugprofile und Stable v0.1.3 werden nicht geändert.
- Rollback ist auf das unveränderte Stable-Tag v0.1.3 dokumentiert.
- Diese Beta wurde nicht auf VM 104 installiert und führt keine produktiven
  Routinganfragen aus.

## English

### Privacy and diagnostics

- Native Home Assistant diagnostics contain no request coordinates, waypoints,
  vehicle request data, credentials, or authentication headers.
- The targeted diagnostic is disabled by default and requires an administrator
  action.
- A short-lived token is valid for exactly one backend calculation attempt and
  is consumed before parallel or subsequent attempts.
- Successful and failed attempts leave no request-diagnostic snapshot in the
  backend.
- The sanitized displayed diagnostic can be copied without another API call;
  when the clipboard is unavailable, a manually selectable text field remains.

### Compatibility and limitations

- The Beta.2 coordinate-loading fix and Beta.3 optional-time fix remain intact.
- Saved routes, vehicle profiles, and Stable v0.1.3 are not changed.
- Rollback to the unchanged Stable tag v0.1.3 is documented.
- This beta was not installed on VM 104 and performs no productive routing
  requests.
