# Camper Route Planner v0.1.2 Stable

## Deutsch

`v0.1.2` ist die Stable-Veröffentlichung auf Basis des geprüften Beta.5-
Stands. Bestehende Config Entries, Fahrzeugprofile, gespeicherte Routen,
Kraftstoffdaten und GPX-Daten bleiben kompatibel.

### Änderungen und Fehlerbehebungen

- Kraftstoffkosten akzeptieren `2,16` und `2.16`; Gesamtverbrauchskosten und
  zusätzlicher Kraftstoffbedarf bleiben getrennt.
- Gespeicherte Kraftstoffwerte werden korrekt wiederhergestellt.
- Dieselpreisänderungen aktualisieren die lokale Kostenschätzung ohne neue
  Routing-Anfrage.
- Eingabefelder behalten Fokus, DOM-Knoten, Cursor, Auswahl und Zwischenwerte;
  echte Chromium-Eingabe `2,16` wurde geprüft.
- v2 und v3 verwenden getrennte NaKordoni-Adapter und Endpunkte. Provider,
  ausgeführte API-Version, Fahrzeugparameter und Restriktionen werden getrennt
  angezeigt bzw. validiert.
- Ungültige gespeicherte Koordinaten werden nicht als Routingpunkte verwendet;
  Grenzen und Verkehrsdaten werden sicher normalisiert.
- GPX-/PDF-Export, mobile Darstellung, gespeicherte Routen und HACS-
  Installationsstruktur bleiben erhalten.

### Bekannte Einschränkung: NaKordoni v3-Maut

Die v3-Mautdaten können für einzelne Länder oder Mautobjekte unvollständig
sein. Die Karte zeigt `complete=false`, Länderwerte, Schätzstatus und
Providerhinweise transparent an. V2-Schätzwerte werden nicht als v3-Ergebnisse
ausgegeben; Lkw-Tarife werden nicht ungeprüft auf private Wohnmobile
übertragen. Motorhome-Routing bleibt eine Planungshilfe.

Die Portugal-Route wurde vom Nutzer mit v2 und v3 praktisch verglichen. Die
Entfernung und Fahrzeit waren gleich; die v3-Mautabdeckung blieb unvollständig.
Für dieses Release wurden keine zusätzlichen kostenpflichtigen Routingaufrufe
ausgeführt.

### Installation

In HACS das Repository als Custom Repository hinzufügen und `v0.1.2` Stable
auswählen. Alternativ das Release-ZIP nach
`custom_components/camper_route_planner/` entpacken.

## English

`v0.1.2` is the Stable release based on the verified Beta.5 state. Existing
config entries, vehicle profiles, saved routes, fuel data, and GPX data remain
compatible.

### Changes and fixes

- Fuel costs accept `2,16` and `2.16`; total fuel demand remains separate from
  additional fuel needed.
- Saved fuel values are restored correctly.
- Diesel-price changes update the local estimate without a new routing request.
- Inputs preserve focus, DOM identity, cursor, selection, and intermediate
  values; real Chromium typing of `2,16` was verified.
- v2 and v3 use separate NaKordoni adapters and endpoints. Provider, executed
  API version, vehicle parameters, and restrictions are separated and validated.
- Invalid saved coordinates are not silently used as route inputs; border and
  traffic data are normalized conservatively.
- GPX/PDF export, mobile presentation, saved routes, and HACS installation
  structure remain available.

### Known limitation: NaKordoni v3 tolls

NaKordoni v3 toll data may be incomplete for individual countries or toll
objects. The card shows `complete=false`, country values, estimate status, and
provider notes transparently. V2 estimates are never presented as v3 results,
and truck tariffs are not applied to private motorhomes without verification.
Motorhome routing is a planning aid.

The user compared the Portugal route with v2 and v3. Distance and driving time
matched, while v3 toll coverage remained incomplete. No additional paid
routing calls were made for this release.

### Installation

In HACS, add the repository as a custom repository and select regular Stable
`v0.1.2`. Alternatively, unpack the release ZIP into
`custom_components/camper_route_planner/`.
