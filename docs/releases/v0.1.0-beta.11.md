# Camper Route Planner v0.1.0-beta.11

## Deutsch

Beta.11 bündelt das Branding aus PR #13 und die Phase-3H-Korrekturen aus PR #14.

### Änderungen und Fehlerbehebungen

- Offizielle lokale Branding-Dateien (`brand/icon.png`, `brand/logo.png` und
  die hochauflösenden Varianten) sind im installierbaren Paket enthalten.
- Die Leaflet-/CARTO-Basiskarte wird auch ohne berechnete Route angezeigt.
  Fehler beim Laden von Kartenkacheln führen zu einer verständlichen
  Fehlermeldung statt zu einer irreführenden leeren Fläche.
- Fahrzeugprofile können über ihre interne Profil-ID gelöscht werden.
  Doppelte Anzeigenamen bleiben eindeutig; gespeicherte Routen werden nur
  nach ausdrücklicher Bestätigung mitgelöscht.
- Fahrzeug-, Kraftstoff-, Provider- und Secret-Statuswerte werden in Deutsch
  und Englisch übersetzt.
- Nakordoni-API-Keys bleiben bei leerem Eingabefeld, Providerwechsel,
  Reload und Migration älterer `data`-/`options`-Einträge erhalten. Eine
  Löschung erfolgt ausschließlich über die explizite Entfernen-Option.

### Installation und Einschränkungen

Beta.11 ist als GitHub-Pre-release für HACS veröffentlicht. Pre-releases müssen
in HACS ausdrücklich aktiviert bzw. ausgewählt werden. Die Release-Prüfung
verwendet isolierte HA-2026.10.1-Fixtures, Mock-Daten und Chromium.

Produktive CARTO-, Geoapify- und Nakordoni-Aufrufe wurden nicht durchgeführt.
Das Projekt verwendet weiterhin deterministisches Mock-Routing und ist keine
geprüfte Wohnmobilnavigation. Ein echter HACS-UI-Installationslauf, WebKit/iOS
und die Darstellung in einer produktiven Home-Assistant-Instanz wurden nicht
validiert. VM 104, produktive Config Entries, API-Schlüssel und andere
Integrationen wurden nicht verändert.

## English

Beta.11 combines the branding from PR #13 with the Phase 3H fixes from PR #14.

### Changes and fixes

- Official local branding files (`brand/icon.png`, `brand/logo.png`, and the
  high-resolution variants) are included in the installable package.
- The Leaflet/CARTO base map is shown even before a route is calculated.
  Tile-loading failures produce a clear user-facing message instead of a
  misleading empty surface.
- Vehicle profiles can be deleted by internal profile ID. Duplicate display
  names remain unambiguous, and saved routes are deleted only after explicit
  confirmation.
- Vehicle, fuel, provider, and secret-status values are translated in German
  and English.
- Nakordoni API keys survive blank fields, provider switches, reloads, and
  migration of older `data`/`options` entries. Keys are removed only through
  the explicit remove option.

### Installation and limitations

Beta.11 is published as a GitHub pre-release for HACS. Explicitly enable or
select pre-releases in HACS. Release validation uses isolated HA-2026.10.1
fixtures, mocked data, and Chromium.

No productive CARTO, Geoapify, or Nakordoni requests were made. The project
still uses deterministic mock routing and is not verified motorhome
navigation. A real HACS UI install run, WebKit/iOS, and rendering in a
productive Home Assistant instance were not validated. VM 104, productive
Config Entries, API keys, and other integrations were not changed.
